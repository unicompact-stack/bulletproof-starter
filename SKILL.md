# SKILL.md — навык «говорящий 2D-персонаж из картинки/фото»

Этот файл — память проекта. **В любой новой сессии сначала читай его**, особенно если
пользователь присылает фото/картинку и просит персонажа, или просит «запустить сервер».
Пользователь — новичок, объясняй просто, по-русски, без жаргона.

## 0. Текущее состояние (не ломай)

- `apple-school/` — игра «Яблочкин — считаем вместе» (урок математики, 5 примеров).
  Плоский SVG-герой — **эталон, пользователь доволен на 100%. Не менять без прямого запроса.**
  Голос — женский `voice-01`, 10 MP3 в `public/audio/`, тексты реплик в `voice-scripts.json`.
- `apple-3d-lab/` — «Лаборатория героев»: **только 2D** (пользователь явно попросил убрать 3D и 2.5D).
  Переключатель «Яблочкин / Кролик», у кролика панель «Движения» и «Эмоции».
- Кролик — собственная стилизация по картинке пользователя (не копия чужого арта).
- Предпросмотры: игра 5173, лаборатория 4174 (`vite preview -- --port 5173|4174`, host 0.0.0.0).
  Пользователь почти каждую сессию просит «запусти сервер» — окружение сбрасывается,
  `node_modules` и `/tmp` удаляются: каждый раз `npm ci` + `npm run build` + старт серверов.

## 1. Процесс добавления нового персонажа из фото/картинки

1. Посмотри картинку, выдели особенности (цвет, уши, нос, зубы, одежда). Не обещай
   «точную копию за секунду» — это стилизация, сходство доводится итерациями.
2. Нарисуй SVG по образцу `apple-3d-lab/src/rabbit-art.js` (viewBox `0 0 300 320`):
   - градиенты шерсти/кожи, мягкий цветной контур (~#2b6f83, ширина 2.5), блики;
   - **анатомия обязательна**: части крепятся внахлёст к телу (уши к макушке, руки к
     плечам, ноги со ступнями к низу) — ничего не висит в воздухе;
   - руки = плечо + кисть с пальцами; ноги = голень + ступня; уши с внутренней частью.
3. Разбей на группы с именами классов (иначе не заработают анимации лаборатории):
   `hero-bounce`, `hero-crown` (+ `ear-left`, `ear-right`), `hero-arm-left/right`,
   `hero-leg-left/right`, `hero-eyes` (+ `eye-left`, `eye-right`), `hero-happy-eyes`,
   брови, `hero-smile`, `hero-mouth`, extras (`tear`, `sad-mouth`, `surprise-mouth`, `tongue-out`).
4. Подключи в `apple-3d-lab/src/main.js` (`SVG_FOR`), добавь в `lab.css` опорные точки
   (`transform-origin` в px user-units) и, если нужны, новые keyframes.
5. Рот: в покое видна `.hero-smile`; при речи она **скрывается** и открывается
   `.hero-mouth` (scaleY от `--mouth`, который VoicePlayer пишет от реальной RMS-громкости).
   Никаких наложений улыбки и открытого рта!
6. Эмоции через `data-emotion` (neutral/joy/sad/surprise), движения через `data-pose`
   (wave/jump/kick/ears/wink/tongue/think/cheer) — см. кнопки в main.js.
7. Озвучка: используй существующие MP3. Именная запись — только если пользователь просит
   (шаблон: hello-Саша/Маша/Миша в `AUDIO` и `greetingFor` в `apple-school/src/lesson.js`).

## 2. Что НЕ делать (наши ошибки)

- **Не добавлять 3D в игру по умолчанию.** 3D «получился так себе», пользователь вернул
   плоского героя; потом и из лаборатории 3D убрали («теряешь качество, когда делаешь много»).
- **Не трогать Яблочкина**, когда просят улучшить кролика («только кролика меняй»).
- **Не мужской голос.** Только женский молодой/детский (выбран voice-01).
- **Не показывать пользователю непроверенное**: он ругал «почему не проверяешь работу».
   После правок — браузерный QA + **сам посмотри скриншоты** (read_file), сравни с референсом.
- **Не висящие/выпуклые детали**: в 3D глаза-шары тонули/торчали, в 2D руки-обрубки
   выглядели «инвалидом». Части должны перекрывать тело и читаться как органы.
- **Не параллелить edit_file по одному файлу** — правки терялись.
- **Не качать браузер с CDN Playwright** (ECONNRESET). Рабочий путь: npm-пакет
  `@sparticuz/chromium`; `executablePath` — это Promise (await!); библиотеки: в
  `node_modules/@sparticuz/chromium/bin` раскрыть `al2023.tar.br` через
  `zlib.brotliDecompressSync` (CLI brotli нет) и `tar -xf al2023.tar` (лягут в `bin/lib/`);
  `LD_LIBRARY_PATH=.../bin/lib:$LD_LIBRARY_PATH`; аргументы `chromium.args`
  (+ `--autoplay-policy=no-user-gesture-required` для звука).
- **Кролик выбирается кликом по кнопке `[data-char="rabbit"]`** — URL-параметра
  `?char=` больше нет; QA-скрипт должен кликать, иначе на странице Яблочкин.
- **Не открывать вторую вкладку в том же браузере** (`--single-process` роняет браузер):
   новый сценарий = новый `playwright.launch(...)`.
- **Не парсить числа из текста интерфейса** regexp'ом «все цифры» (цифра из «3D» прилипла
   к счётчику треугольников). Бери число рядом с меткой.
- Не обещать идеальный голос/сходство с первого раза; не использовать чужой защищённый
   арт/аудио из оригинального Gambitik.

## 3. Чек-лист QA после правок персонажа

1. `npm test` и `npm run build` в изменяемом проекте.
2. Браузерный QA (скрипты-образцы лежали в `/tmp/lab-browser/*.mjs`; `/tmp` живёт одну
   сессию — пиши заново): рот следует за звуком (`--mouth` меняется, >0.05), улыбка
   opacity 0 во время речи и 1 в покое, каждая кнопка движения даёт свою
   `animationName`, эмоции меняют `opacity`/`transform`, моргание навешано.
3. Скриншоты: нейтральный + эмоции + мобильная ширина 390 (без горизонтальной прокрутки).
4. `pageerror`/внешние запросы — пусто. Регрессия второго персонажа и игры.

## 4. Полезные файлы

- `apple-3d-lab/src/rabbit-art.js` — образец качественного SVG-персонажа.
- `apple-3d-lab/src/main.js`, `lab.css` — переключение героев, движения, эмоции, keyframes.
- `apple-school/src/main.js` — фасад `mascot` (SVG; 3D только по `?3d=1`, выключено по умолчанию).
- `apple-school/src/art.js` — эталонный Яблочкин; `audio.js` — VoicePlayer (RMS → рот).
- `apple-school/voice-scripts.json` — тексты реплик для переозвучки.
