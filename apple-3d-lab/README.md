# Лаборатория героев — качественная 2D-анимация

Эксперимент рядом с уроком. Основное приложение `apple-school/` здесь не меняется.

По просьбе пользователя из лаборатории убраны 3D и псевдообъём: остался только
**плоский, аккуратно нарисованный и плавно анимированный** персонаж. Доступны два героя:

- **Яблочкин** — тот же рисунок, что в уроке.
- **Кролик** — собственная стилизация по мотивам картинки пользователя: градиенты,
  мягкие контуры, большие глаза, розовый нос и фирменные зубки.

## Что умеет каждый герой

- Моргает и слегка «дышит» в покое.
- Машет рукой при приветствии, думает (качаются ухо/листик), радуется (прыжок и счастливые глаза).
- В покое улыбается; когда говорит, улыбка скрывается и открывается рот с верхними
  зубками и язычком, который тянется от **реальной громкости MP3** — без наложений.
- Голос и записи — те же, что в уроке (`@apple-school/audio.js`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:4174
npm run build
npm run preview
```

## Структура

- `src/main.js` — переключение героев, кнопки речи, реакции.
- `src/rabbit-art.js` — SVG-кролик с группами для анимаций.
- `src/lab.css` — оформление и keyframes (моргание, волна, раздумье, радость, рот).

Рисунок Яблочкина, голосовой плеер и список реплик берутся из `../apple-school/src`
через алиас `@apple-school`, чтобы не хранить копию.
