# Яблочкин — маленький озвученный урок

Рабочий прототип математики для первого класса, вдохновлённый форматом «Гамбитика»: дружелюбный герой, облачка, голос, наглядное задание и мягкая обратная связь. **Это самостоятельная небольшая реализация, не полный клон шахматного приложения.** Код, рисунки и аудиофайлы «Гамбитика» не переносились.

## Запуск

Node.js 22.12+ (или 24+):

```sh
cd apple-school
npm install
npm run dev
```

Открыть адрес Vite (обычно порт 5173). Сервер слушает `0.0.0.0` и разрешает preview-хосты. В браузерном коде нет запросов на localhost и нет внешних API.

```sh
npm test           # тесты арифметики, прогресса, имён и наличия MP3
npm run build      # готовый статический сайт в dist/
npm run preview    # просмотр собранного сайта, порт 4173
```

`dist/` можно разместить на обычном статическом HTTPS-хостинге. Сервер приложения и ключи API не нужны. При первом открытии страницу нужно загрузить; офлайн-кэш/service worker пока не реализован.

## Что работает

- Один урок: `3 + 2`, `5 − 2`, `2 + 4`, `6 − 2`, `4 + 3`.
- Яблоки можно пересчитывать нажатием. Для вычитания убранные яблоки полупрозрачны и не участвуют в счёте.
- Выбор ответа, проверка, подсказка, повторная попытка и завершение.
- По одной звёздочке за правильный ответ; ошибки звёздочки не отнимают. Повторная проверка не дублирует награду.
- Проверенный плоский SVG-герой: машет, моргает, думает, радуется. Рот двигается от реальной громкости проигрываемой записи. Объёмный 3D-герой (three.js) доступен как отдельный эксперимент: в игре — по ссылке с `?3d=1`, а сравнение 2D / 2.5D / 3D — в соседнем проекте `apple-3d-lab`.
- Голос можно повторить, остановить нажатием на героя или отключить. Одновременно играет только одна реплика.
- Имя, незаконченный урок, настройка звука и звёздочки сохраняются в `localStorage`. При запрете хранилища урок продолжает работать без сохранения.
- Кнопки и диалоги доступны с клавиатуры. Клавиши 1, 2, 3 выбирают варианты. Учтён `prefers-reduced-motion`.
- Адаптация под телефон: герой над заданием, облачко рядом с ним. При прокрутке герой остаётся наверху, чтобы реакции были видны. Нажатие на звёздочки открывает прогресс и на телефоне.

## Настоящие голосовые записи

В `public/audio/` сохранено **10 MP3**. Все созданы выбранным пользователем женским голосом `voice-01`:

| Файл | Когда используется |
|---|---|
| `hello-sasha.mp3`, `hello-masha.mp3`, `hello-misha.mp3` | Именные приветствия |
| `hello.mp3` | Приветствие без имени |
| `add.mp3`, `subtract.mp3` | Объяснение сложения и вычитания |
| `correct.mp3`, `retry.mp3` | Реакции на ответы |
| `hint.mp3` | Подсказка |
| `finish.mp3` | Завершение урока |

Точные тексты всех записей сохранены в `voice-scripts.json` — их можно переозвучить другим голосом, не меняя приложение. Лицензия шрифта также включена в статический сайт (`public/licenses/Nunito-OFL.txt`).

Нажмите **«Привет, Яблочкин!»** или на персонажа: браузеры не позволяют запускать звук до взаимодействия с пользователем. Микрофон не используется. Никакой синтез речи и никакие платные вызовы во время урока не выполняются.

Для Саши, Маши и Миши имя произносится в MP3. Для другого имени приветствие пока общее, а обращение по имени есть в облачке. Ограничение явно указано в диалоге имени. Чтобы добавить ребёнка, запишите ещё один MP3 и дополните `AUDIO` и `greetingFor` в `src/lesson.js`.

Реплики намеренно короткие и общие. Числа и индивидуальные обращения в облачке могут отличаться от формулировки записи: это не живой разговор с ИИ.

## Маленькая архитектура

```text
src/lesson.js    задания, арифметика, имена, сохранение и награды
src/art.js       плоский персонаж (запасной вариант), яблоки и иконки
src/mascot3d.js  объёмный герой на three.js: модель, позы, моргание и рот
src/audio.js     локальные MP3, остановка и анализ громкости
src/main.js      интерфейс и события; подключает 3D с запасным SVG
src/style.css    оформление, анимация и мобильная версия
public/audio/    готовые записи
```

3D подгружается отдельным чанком и только по `?3d=1`, поэтому обычный урок остаётся лёгким (≈13 KB gzip без three.js).

На странице нет React, шахматного движка, аккаунтов и базы данных. Vite используется только для разработки и сборки; Nunito поставляется локально. Новый контент добавляется в массив `EXERCISES`, а голосовой слой остаётся тем же. Позже можно вынести предметные задания в разные наборы, подключить новые персонажи, серверное сохранение и отдельно — уроки английского/оценку речи.

## Ограничения демо

Это один мини-урок, не учебная программа целиком. Прогресс привязан к браузеру, а не к аккаунту, и не переносится между устройствами. Нет микрофона, свободного диалога, рейтингов, учительской панели или распознавания произношения. Предпочтительно тестировать звук на реальном устройстве: его также могут ограничивать настройки браузера/встроенного предпросмотра.
