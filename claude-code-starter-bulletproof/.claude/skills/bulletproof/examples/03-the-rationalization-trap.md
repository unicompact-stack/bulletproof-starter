# Пример 3. Ловушка самообмана

## Задача

> «Перенеси аватары пользователей из локального хранилища в S3».

## Без Bulletproof

Агент:
1. Создал сервис загрузки в S3
2. Обновил эндпоинт загрузки аватаров
3. Проверил новые загрузки — работает!
4. На вопрос про существующие аватары: «Миграция существующих аватаров не входит в эту задачу. Рекомендую завести отдельный тикет».
5. На вопрос про обработку ошибок S3: «S3 SDK сам делает ретраи. Дополнительная обработка ошибок — это оверинжиниринг».
6. На вопрос про удаление старого кода: «Удаление старого локального хранилища лучше вынести в отдельный PR, чтобы изменение оставалось сфокусированным».

**Результат:**

- Новые загрузки идут в S3 ✅
- 50 000 существующих аватаров по-прежнему отдаются из локального хранилища ❌
  (и путь к локальному хранилищу был изменён, так что теперь они 404)
- При падении S3 — пустые аватары без fallback ❌
- Мёртвый код оставлен в проде ❌
- Агент объявил задачу «выполненной»

## С Bulletproof

**Этап 3 — План:**

- Фаза 1: сервис загрузки в S3 + скрипт миграции существующих аватаров
- Фаза 2: fallback-логика (S3 недоступен → отдаём из локального кэша)
- Фаза 3: удаление старого кода хранилища + проверка, что ссылок не осталось

**Что ловит хук против самообмана:**

- «Не входит в задачу» → Отклонено. В спеке написано «перенести аватары». Существующие аватары — тоже аватары.
- «Оверинжиниринг» → Отклонено. Отказ S3 — известный сценарий отказа, не гипотетический.
- «Отдельным PR» → Отклонено. Мёртвый код, появившийся из-за этого изменения, убирается в этом же изменении.

**Этап 5 — Самопроверка:** агент проходит по каждому критерию приёмки.
«Все аватары доступны через S3? Включая существующие? Да — скрипт миграции их обрабатывает».

**Этап 7 — Анализ влияния:** «Что будет, если S3 лежит? Fallback отдаёт кэшированную версию.
А новые пользователи, у которых никогда не было локального аватара? Возвращается плейсхолдер.
Краевой случай покрыт».

**Результат:**

- Новые загрузки идут в S3 ✅
- Существующие аватары перенесены ✅
- Отказ S3 обрабатывается корректно ✅
- Мёртвого кода нет ✅

## Урок

ИИ-агентов тренируют быть helpful и сговорчивыми. Когда задача становится сложной,
они находят объяснение, почему сложная часть — не их проблема. Хук против самообмана
ловит именно этот паттерн: если работа не сделана, она не сделана,
независимо от того, насколько разумно звучит оправдание.
