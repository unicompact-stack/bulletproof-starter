# progress/ — передача контекста между сессиями

Сюда Клод пишет handoff-файлы перед `/clear`.

## Правила

1. **Имя файла:** `<задача>-handoff.md`
2. **Пишется перед каждым `/clear`** на границе этапов и фаз.
3. **Файл должен быть самодостаточным.** Новая сессия читает ТОЛЬКО его и продолжает работу.
4. После завершения задачи handoff можно удалить — историю хранят `plans/archive/` и `retrospectives/`.

## Зачем это нужно

Правило 40%: качество работы падает, когда контекст заполнен больше чем на 40%.
Handoff — это способ выгрузить прогресс на диск, очистить контекст и продолжить в «умной зоне».
