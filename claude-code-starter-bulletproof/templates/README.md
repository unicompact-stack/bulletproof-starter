# templates/ - образцы файлов для генерации

Клод берёт файлы отсюда как образцы, когда создаёт конкретные файлы под проект пользователя.

## CLAUDE.md.tmpl

Шаблон для генерации корневого `CLAUDE.md` на шаге 10a AUTOPILOT. Содержит плейсхолдеры:
- `{{PROJECT_NAME}}` - имя проекта
- `{{PROJECT_ONE_LINER}}` - одно предложение о чём проект
- `{{STACK}}` - технический стек
- `{{LANGUAGE_RULE}}` - на каком языке Клоду общаться с пользователем

Клод заполняет плейсхолдеры ответами из интервью и записывает в корень как `CLAUDE.md`.

## claude-settings.json.example

Образец `.claude/settings.json` после прохождения шагов 4, 5 и 6 AUTOPILOT
(звуковые хуки + запреты безопасности + хуки Bulletproof).

**Это не валидный рабочий файл** (Claude Code может ожидать свою версию формата). Образец даёт Клоду понимание структуры, в реальном файле Клод использует актуальный формат Claude Code.

Структура:

- `hooks.PreToolUse` (matcher `Bash`) - блокировка `git push` в main/master, `rm -rf /`, `DROP TABLE`.
  Возвращает `exit 2` = команда отклонена.
- `hooks.Stop` - **два хука в одном массиве, оба выполняются:**
  1. `type: command` - звук при завершении задачи
  2. `type: prompt` - проверка на самообман (Bulletproof): агент-оценщик отклоняет
     ответ, если Клод оправдывает незавершённую работу
- `hooks.Notification` - звук при запросе разрешения
- `permissions.deny` - запреты опасных команд (4 концептуальные категории, 9 regex-правил)

Кросс-платформенная команда звука использует `afplay` (Mac) с fallback на PowerShell `console.beep` (Windows) и терминальный bell `\a`.

⚠️ **Частая ошибка:** при добавлении хука из Bulletproof Клод перезаписывает весь массив `Stop`
и звуковое уведомление пропадает. Правильно - добавить второй элемент в массив, не затирая первый.
