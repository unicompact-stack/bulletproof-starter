# Handoff: курс «Душа компании» — передача между сессиями

**Дата:** 2026-11-05
**Зачем файл:** чтобы новый диалог подхватывал работу за 10 секунд, а не
восстанавливался по памяти. Читается первым.

## Правило работы

- Длинный диалог подходит к лимиту → пишешь: **«обнови HANDOFF.md»**.
- Новый диалог начинаешь с: **«прочитай communication-course/HANDOFF.md и
  продолжай»**.
- Всё, что не записано сюда и не закоммичено в ветку, при смене сессии
  теряется.

## Goal

Личный веб-курс по коммуникативным навыкам: 6 уроков с теорией и
практикой, прогресс в браузере. Пользователь один — автор. Подробности —
`PROJECT.md`.

## Approach

- Контент — канонические markdown-файлы в `content/`; приложение читает их
  через виртуальные модули Vite, копий нет.
- Источники — реестр `library/sources.md` плюс конспекты `library/notes/`.
  Приложение показывает их на странице «Библиотека» из того же файла.
- Прогресс — только `localStorage`, без бэкенда (принцип приватности).
- Методология — лёгкий Bulletproof: спека → план → код → ретро.

развивать его сейчас не нужно. Единственное исключение: правки, без

## Key Files

- `PROJECT.md` — зачем проект, для кого, рамки. Читать первым.
- `docs/spec.md` — чек-лист готовности MVP. Единственный критерий «готово».
- `docs/plan.md` — фазы и их gate.
- `content/lesson-01.md … lesson-06.md` — тексты уроков, источник правды.
- `library/sources.md` — реестр источников, его же читает приложение.
- `app/src/lib/lesson.ts` — парсер уроков; формат markdown менять только
  синхронно с ним.
- `app/vite-plugin-content.ts` — мост между `content/` и приложением.

## Key Decisions Made

- **Без AI и бэкенда на MVP** — дорого и тянет инфраструктуру; вернуться к
  вопросу после фазы 3.
- **Письменные упражнения + чек-лист самопроверки** вместо AI-собеседника
  и видео.
- **НЛП подаётся с оговоркой** — доказательной базы нет (S-027, S-028),
  приёмы оставлены как субъективно работающие.
- **Контент не дублируется в приложении** — только виртуальные модули,
  иначе тексты разъедутся.
- **55 источников со статусами** — «проверено» можно цитировать,
  «на проверке» использовать осторожно, «отклонено» оставлено, чтобы не
  искать повторно.
- **Порядок уроков от внутреннего к внешнему** — сначала страх и внимание,
  потом small talk, потом шутки и тосты.
