# Контекст проекта

**Название:** Курс «Душа компании»
**Дата интервью:** 2026-11-05
**Формат:** личный проект, соло
**Методология:** лёгкая (спека → план → код → ретро), на базе Bulletproof

## Идея одним предложением

Веб-курс, который тренирует навыки общения — остроумие, импровизацию,
сторителлинг, умение рассказывать анекдоты и тосты, — чтобы человек
чувствовал себя «душой компании».

## Зачем это нужно

Автор хочет системно прокачать коммуникативные навыки. Сейчас это «куча
наработок и упражнений» без структуры. Нужен понятный маршрут: что читать,
что тренировать, как понять, что стало лучше.

## Для кого

- **Основной пользователь:** автор проекта (один человек).
- Публичный запуск, регистрация и другие пользователи на MVP не входят.
- Это важно: не строим лишнего «для будущих пользователей».

## Что будет делать продукт

- Даёт 6 уроков по темам общения.
- В каждом уроке: короткая теория из литературы + практическое упражнение.
- Сохраняет ответы и прогресс в браузере.
- Показывает, какие уроки пройдены и что осталось.

## Рамки

| Параметр | Решение |
|---|---|
| Платформа | Веб-приложение |
| Стек | Выбирается на этапе плана; рекомендация — React + Vite + TypeScript + Tailwind |
| Бэкенд | Нет на MVP, хранение в localStorage |
| AI | Отложено, решаем после этапа 1 |
| Срок MVP | 1–2 недели |
| Язык | Русский |
| Хранение проекта | Папка `communication-course/` в этом репозитории |
| Контент | Готовые методики и книги; первый этап — их поиск и разбор |

## Принципы

1. **Практика важнее теории.** Урок без упражнения — не урок.
2. **Один урок = одно действие.** Не расползаться на десять тем.
3. **Без выдуманных фактов.** Только то, что есть в литературе или в
   наработках автора.
4. **Приватность.** Ответы и прогресс не покидают браузер.
5. **Сначала польза, потом украшения.** Никакой геймификации до MVP.

## Что уже есть

Автор передал большой массив наработок (переписка с AI, 2026-11-05): описание
проблемы «ментального пузыря», ТОП-6 методов, НЛП-инструменты, темы для
разговора, 12 приёмов импровизации, модель «Ромашка», блок про скорость
мышления. Всё разобрано и сохранено в `materials/2026-11-05-mental-bubble.md`.

**Что это меняет:** курс строится не вокруг абстрактных «навыков общения», а
вокруг реальной проблемы автора — «голова пустая, не могу ответить». Исходная
идея «души компании» (остроумие, анекдоты, тосты) остаётся, но опирается на
эту базу.
