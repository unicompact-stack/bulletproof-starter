# План работ

**Дата:** 2026-11-05

## Журнал решений

**Выбрано:** структурированные письменные упражнения с самопроверкой по
чек-листу. Пользователь пишет ответ в поле, затем сам сверяется с критериями.

**Почему:** письменная формулировка заставляет додумать мысль до конца, а
чек-лист даёт обратную связь без внешнего собеседника и без бэкенда.

### Отклонённые альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| AI-собеседник для отработки диалогов | Дорого по времени и деньгам, тянет за собой бэкенд и ключи; на MVP не нужен |
| Просто читать книги по списку | Нет практики — навык не формируется, это противоречит принципу №1 |
| Публичный курс для всех | Распыление: дизайн, регистрация, поддержка. Пользователь пока один |
| Видео-уроки | Производство дороже текста в разы, правки медленные |

## Фазы

### Фаза 0 — исследование литературы

Найти и разобрать источники, согласовать темы уроков.

**Gate:** минимум 5 источников (фактически разобрано 14), по каждому ясно,
что именно берём и в какой урок; темы уроков согласованы с автором. ✅

### Фаза 1 — контент-каркас

Написать 6 уроков: в каждом цель, теория, 2–3 упражнения, самопроверка,
поле для ответа. Всего 15 упражнений.

**Gate:** все 6 файлов существуют, формат единый, упражнений ≥ 15. ✅

### Фаза 1.5 — библиотека источников

55 источников в реестре, 55 конспектов, рубрика отбора, промпт разбора,
журнал поиска.

**Gate:** у каждого источника есть ID, оценка, статус и привязка к уроку. ✅

### Фаза 2 — MVP-приложение

React + Vite + TypeScript + Tailwind, контент читается из `content/` через
виртуальные модули, прогресс в localStorage, страница библиотеки, 26 тестов.

**Gate:** `npm run build` проходит, `npm test` зелёный. ✅

### Фаза 3 — проверка и ретро

Пройти все 6 уроков как обычный пользователь, сверить результат со спекой,
заполнить ретро по шаблону.

**Gate:** чек-лист спеки закрыт полностью, ретро записано. ⏳

## Правила

- Каждая фаза — отдельный сеанс с чистым контекстом.
- Не начинать фазу, пока не закрыт gate предыдущей.
- Новые хотелки не делаем «по ходу» — они идут в `docs/open-questions.md`.
- Перед словом «готово» — сверка со спекой, а не ощущение.
