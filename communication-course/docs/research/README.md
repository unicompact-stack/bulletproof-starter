# Как ведём исследование

Правила этапа 0. Нужны, чтобы обзор литературы не превратился в свалку
ссылок.

1. **Один источник — одна строка в таблице.** Название, автор, год, тип,
   ссылка. Без этого источник не считается найденным.
2. **Фиксируем применимость.** По каждому источнику отвечаем на вопрос:
   «что конкретно мы отсюда берём и в какой урок». Если ответа нет —
   источник не нужен.
3. **8–12 источников на MVP.** Этого достаточно для 6 уроков. Больше —
   риск утонуть в чтении вместо практики.
4. **Каждый вывод со ссылкой.** Утверждение без источника в контент не
   попадает.
5. **Критическая проверка обязательна.** Отдельно отмечаем, что имеет
   научную базу, а что — популярная практика без доказательств.
6. **В конце — рекомендация.** Обзор заканчивается не списком, а решением:
   какие темы берём в уроки.

## Что не делаем

- Не пересказываем книги целиком — только то, что станет упражнением.
- Не храним полные тексты (копирайт). Ссылка + конспект.
- Не выдумываем номера страниц и цитаты. Нет доступа — пишем «нет доступа».
