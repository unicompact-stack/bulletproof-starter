# Спека: MVP курса «Душа компании»

**Дата:** 2026-11-05
**Статус:** согласована, этап 2 закрыт по чек-листу

## Проблема

У автора накопилась куча разрозненных наработок по общению: выписки,
упражнения, переписки с AI, обрывки методик. Нет структуры, нет маршрута,
непонятно, с чего начать и как понять, что стало лучше. В результате
наработки не превращаются в навык.

Поверх этого — конкретная личная проблема: «ментальный пузырь». В момент
разговора голова пустая, ответ приходит через пять минут после того, как он
был нужен.

## Цель

Сделать MVP, в котором **урок проходится за один сеанс**, **ответ
сохраняется** и **прогресс виден**. Не энциклопедия по общению, а тренажёр
с шестью понятными шагами.

## Измеримый результат

- 6 уроков, каждый проходится за 10–20 минут.
- Ответы переживают перезагрузку страницы.
- Прогресс («Пройдено N из 6») виден на главном экране.

## Скоуп MVP

### Входит

- Главный экран со списком 6 уроков и статусом каждого.
- Урок: теория до 2 страниц + 1–2 упражнения + поле для ответа.
- Сохранение ответов и отметок в `localStorage`.
- Восстановление сохранённого при открытии урока.
- Экран итогов по курсу (прогресс-бар и процент на главном).
- Адаптивная вёрстка от 390 px.
- Весь текст — на русском.

### Не входит

- AI-собеседник и автоматический разбор ответов.
- Регистрация, бэкенд, база данных.
- Платежи и подписки.
- Публичный доступ для других пользователей.
- Мобильное приложение (только веб).
- Геймификация: очки, стрики, бейджи.
- Социальные функции: комментарии, рейтинги, шаринг.

## Критерии готовности

- [x] Главный экран со списком 6 уроков.
- [x] В каждом уроке теория и минимум одно упражнение.
- [x] Ответ сохраняется в localStorage и восстанавливается после перезагрузки.
- [x] Прогресс урока виден на главном экране.
- [x] Любой урок проходится за один сеанс без ошибок.
- [x] Нет ошибок в консоли браузера.
- [x] `npm run build` проходит.
- [x] Вёрстка не ломается на 390 px.
- [x] Все тексты на русском, без заглушек.
- [x] Нет «мёртвых» кнопок.
- [x] Страница «Библиотека» открывается, показывает 55 источников и
      фильтрует по уроку и статусу.

## Что считается «не готово»

Любой пункт чек-листа без отметки. Половина фичи — это не готово.
Формулировка «работает, но...» означает «не работает».
