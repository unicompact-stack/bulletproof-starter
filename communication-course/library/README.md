# Библиотека источников

Единственное место, где живут источники курса. Любое утверждение в уроке
опирается на строку из `sources.md`.

## Правила

1. **Нет источника — нет утверждения.** Если нечем подтвердить, фраза в
   урок не попадает.
2. **Название и автор обязательны.** Без них источник не принимается.
3. **Полные тексты не храним.** Только ссылка и конспект — это вопрос
   копирайта и объёма репозитория.
4. **Один источник — один конспект** `notes/S-XXX.md`. ID сквозной,
   не переиспользуется даже после отклонения.
5. **Ничего не выдумываем.** Нет доступа к тексту — так и пишем:
   «нет доступа». Цитаты и страницы по памяти не восстанавливаем.
6. **Все названия — на русском.** Если источник англоязычный, в реестре
   стоит перевод названия, а оригинал — в карточке, в поле
   «Оригинальное название». Имена авторов тоже кириллицей: «Файн Д.»,
   а не «Fine D.». Исключение — названия организаций.
7. **Русскоязычные источники в приоритете.** При прочих равных берём
   русский источник: его можно читать без перевода. Англоязычный берём,
   когда он первоисточник или когда русского аналога нет.

## Статусы

| Статус | Что значит |
|---|---|
| `inbox` | Найден, ещё не разобран |
| `на проверке` | Разобран, но доказательность или выходные данные под вопросом |
| `проверено` | Разобран, оценён по рубрике, можно ссылаться в уроке |
| `отклонено` | Не проходит рубрику. Остаётся в реестре, чтобы не искать повторно |

## Как добавить источник

1. Положить краткое описание в `inbox/` (см. `inbox/README.md`).
2. Прогнать через промпт `prompts/extract-source.md`.
3. Оценить по `RUBRIC.md`.
4. Создать `notes/S-XXX.md` и добавить строку в `sources.md`.

## Файлы

- `sources.md` — реестр, 55 источников.
- `RUBRIC.md` — критерии отбора и красные флаги.
- `SEARCH-LOG.md` — что искали, какими запросами, что не взяли и почему.
- `notes/` — конспекты S-001…S-055.
- `prompts/extract-source.md` — промпт для разбора нового источника.
- `inbox/` — необработанные находки.
