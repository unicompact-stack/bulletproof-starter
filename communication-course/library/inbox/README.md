# Inbox: новые источники

Сюда складывается всё найденное, что ещё не разобрано. Задача папки —
чтобы находка не потерялась в закладках и не прервала текущую работу.

## Как положить источник

Один источник — один файл `YYYY-MM-DD-короткое-имя.md`:

```markdown
# Название

- **Автор:**
- **Ссылка:**
- **Где нашёл:**

## Почему важен

Одно-два предложения: какой вопрос курса это закрывает.

## Что предположительно возьмём

- Урок N: ...
```

## Правила

- Минимум для приёма: **название, автор, ссылка**. Без них — не источник,
  а воспоминание.
- Не разбираем сразу. Разбор — отдельный сеанс по
  `prompts/extract-source.md`.
- После разбора файл из `inbox/` удаляется, вместо него появляется
  `notes/S-XXX.md` и строка в `sources.md`.
- Если источник отклонён — всё равно заводим карточку со статусом
  «отклонено», чтобы через месяц не искать его заново.
