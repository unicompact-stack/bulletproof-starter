# Контент курса

Канонические тексты уроков. Приложение не хранит копии — оно читает эти
файлы через виртуальные модули Vite. Правим здесь, в приложении меняется
автоматически.

## Файлы

- `course-outline.md` — структура урока, карта курса, логика
- `lesson-01.md` — Ментальный пузырь
- `lesson-02.md` — Собрать ответ за 10 секунд
- `lesson-03.md` — Вернуться в момент
- `lesson-04.md` — О чём говорить
- `lesson-05.md` — Импровизация
- `lesson-06.md` — Анекдоты и тосты

## Правила

1. **Формат фиксированный.** Заголовок `# Урок N. Название`, затем
   `**Цель:**`, `**Время:**`, `**Понадобится:**`, разделитель `---`,
   затем секции `##`. Парсер зависит от этого.
2. **Секции `## Самопроверка` и `## Поле для ответа` обязательны** и идут
   последними. Всё, что выше, считается телом урока.
3. **Чекбоксы `- [ ]` только в самопроверке.** В теории их быть не должно —
   парсер соберёт их в чек-лист.
4. **Теория — до 2 страниц.** Если не помещается, значит, в уроке две темы.
5. **Минимум одно упражнение в уроке.** Урок без практики не публикуется.
6. **Утверждение без источника не пишем.** Ссылка на ID источника из
   `library/sources.md` — в формате «(S-001)».
7. Тексты — на русском, без англицизмов там, где есть русское слово.
