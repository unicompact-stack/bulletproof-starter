# S-006. Sleep Deprivation and Vigilant Attention

- **Автор:** Lim J., Dinges D. F.
- **Год:** 2008
- **Тип:** мета-анализ
- **Ссылка:** https://doi.org/10.1196/annals.1417.002
- **Доступ:** реферат
- **Статус:** проверено
- **Уроки:** 1, 3

## Что говорит

- Лишение сна сильнее всего бьёт по устойчивому вниманию.
- Эффект воспроизводится в десятках исследований.
- Скорость простой реакции падает заметнее, чем сложные рассуждения.
