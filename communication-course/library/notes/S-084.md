# S-084. Спасите котика! И другие секреты сценарного мастерства

- **Оригинальное название:** Save the Cat! The Last Book on Screenwriting You'll Ever Need
- **Автор:** Снайдер Б.
- **Год:** 2005
- **Тип:** практическое руководство
- **Ссылка:** —
- **Доступ:** печатное издание
- **Статус:** на проверке
- **Уроки:** 6
- **Тема:** T-05

## Что говорит

- Структура истории как последовательность опорных точек.
- Приём «спасите котика»: герою дают поступок, который вызывает симпатию, до начала основного действия.
- Удержание внимания через смену ожиданий.

## Что берём

- Тема T-05: самая практичная из книг по структуре истории, подходит для коротких устных историй.
- Приём с ранней симпатией переносится на рассказ о себе в компании.

## Ограничения

- Написано про полнометражный сценарий: прямой перенос на устную историю требует сокращения в разы.
- Никаких проверок, это ремесленный стандарт индустрии.
- Год русского перевода не сверен.
