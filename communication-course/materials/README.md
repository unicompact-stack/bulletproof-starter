# Материалы автора

Сюда складываются исходные наработки: выписки, переписки, конспекты,
упражнения, ссылки.

## Правила

- Один вброс материалов — один файл с датой: `YYYY-MM-DD-тема.md`.
- Исходник не редактируем «по смыслу» — только структурируем.
- Всё, что идёт в уроки, помечается явно: «→ урок N».
- Если утверждение требует проверки по литературе — помечаем «проверить».
