# FSM PRO — система управления выездными работами

Офлайн-first система выездных работ: диспетчерский дашборд, мобильная часть для мастеров, контроль статусов, фотоотчётов и актов выполненных работ.

## 🚀 Быстрый запуск

```bash
npm install
npm run dev
```

Откроется экран входа. Коды доступа:

| Код | Роль |
|-----|------|
| `1111` | Работник (мастер) |
| `9999` | Руководитель |

Демо-режим (обучение) — отдельной кнопкой на экране входа.

## 🛠 Стек

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS 4** — стилизация (светлый фон `#F4F7FA`, белые карточки, синий акцент `#168BEA`, зелёные статусы `#2CCB70`)
- **Lucide React** — иконки
- **IndexedDB / localStorage** — офлайн-хранилище с очередью синхронизации

## 👥 Роли и разделы

| Роль | Разделы |
|------|---------|
| **Работник (мастер)** | Все задачи (витрина), Мои, Чат, Помощь |
| **Руководитель** | Главная, Задачи, Бригады, Проверка |

Подробнее о статусе разработки и планах — в [`CHANGELOG.md`](./CHANGELOG.md).

## 🔄 Статусы задач (только 5)

| Статус | Название | Цвет |
|--------|----------|------|
| `new` | Новая | Зелёный `#2CCB70` |
| `assigned` | Назначена | Фиолетовый `#9546D8` |
| `in_progress` | В работе | Синий `#168BEA` |
| `under_review` | На проверке | Пурпурный `#9546D8` |
| `completed` | Выполнена | Зелёный `#2CCB70` |

### Просроченные задачи
Просрочка — **не отдельный статус**, а визуальная пометка (`isOverdue: true`) на карточке задачи. Статус остаётся из 5 базовых.

### Возврат на доработку
При отклонении отчёта диспетчером задача возвращается в статус **«В работе»** с комментарием в истории.

## 📋 Запуск и тестирование

### Сценарий мастера (полный цикл)

1. **Список задач** — выберите задание из списка
2. **Карточка & Маршрут** — просмотрите адрес, постройте маршрут
3. **«Начать работу»** — статус переходит в «В работе»
4. **Чек-лист & Фото** — отмечайте пункты, загружайте фото
5. **Подпись & Акт (PDF)** — подпись заказчика и формирование акта

### Чат с рабочими
Между диспетчером и бригадой работает общий чат:
- **Диспетчер**: блок «Чат с рабочими» в правой колонке панели руководителя
- **Бригада**: карточка «Чат с диспетчером» в разделе «Профиль» мобильной части
- Сообщения сохраняются в localStorage (`fsm_chat`) и доступны с обеих сторон

### Демо-режим

- **Авто-заполнение этапов** — кнопка в шапке быстро отмечает чек-лист, добавляет демо-фото и списывает материалы
- **Переключение Online/Offline** — имитация автономного режима с очередью синхронизации
- **Сброс демо** — возврат к исходным мок-данным
