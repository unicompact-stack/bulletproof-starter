# Как запустить FSM PRO на своём компьютере

Версия: этапы 1–4 (фото из галереи, доработка-баннеры, «Я на объекте»,
личный чат, коды в админке, сотрудники, аватары) + номер сборки на экране входа.

---

## Вариант 1. Полноценный запуск (рекомендую)

Нужен **Node.js** (версия 20 или новее): скачать с https://nodejs.org и установить.

1. Распакуйте архив в любую папку, например `C:\fsm-pro` (или `~/fsm-pro`)
2. Откройте терминал в этой папке:
   - **Windows**: Пуск → наберите `cmd` → `cd C:\fsm-pro`
   - **macOS/Linux**: Терминал → `cd ~/fsm-pro`
3. Выполните по очереди:

```bash
npm --prefix app install   # скачать зависимости (2–3 минуты, один раз)
npm --prefix app run dev   # запустить сервер
```

4. Откройте в браузере **http://localhost:5173**

Вход: `1111` — мастер, `9999` — руководитель, или кнопка «Демо-режим».
Номер сборки виден внизу экрана входа (дата и время запуска сервера).

Остановка сервера: в терминале нажать `Ctrl+C`.

---

## Вариант 2. Без установки Node.js (готовая сборка)

В архиве уже лежит папка **`dist/`** — собранный сайт. Нужен любой статический сервер:

**Через Python** (обычно уже установлен на macOS/Linux; на Windows — из Microsoft Store):

```bash
cd fsm-pro/dist  # (сборка уже внутри архива)
python -m http.server 8080
```

Откройте **http://localhost:8080**

**Через Node.js** (если есть): `npx serve dist`

> Просто открыть `index.html` двойным кликом НЕЛЬЗЯ — браузеры блокируют
> ES-модули при открытии с диска (file://). Нужен любой локальный сервер.

---

## Данные и офлайн

- Всё работает локально в браузере: задачи, фото, чат (IndexedDB + localStorage).
- Интернет нужен только для аватарок «моковых» сотрудников ( Unsplash ) — без сети вместо них цветные круги с инициалами, это нормально.
- База Supabase НЕ подключена (по решению владельца) — как и раньше, всё локально.

## Обновить версию на GitHub Pages (когда решите)

1. Создайте файл `.env` рядом с `deploy_gh.py`:

```
GITHUB_TOKEN=ваш_токен
```

Токен: github.com → Settings → Developer settings → Personal access tokens
(право `repo`). Это тот же токен, что использовался раньше.

2. Выполните:

```bash
npm --prefix app install
npm --prefix app run build
python deploy_gh.py
```

Скрипт сам загрузит `dist/` в репозиторий и обновит GitHub Pages.
Сайт: https://unicompact-stack.github.io/fsm-pro/

Сервис-воркер уже настроен на автообновление: после деплоя пользователям
достаточно 1–2 раз обновить страницу в первый раз, дальше версии будут
подтягиваться сами.

## Что в этой версии нового (кратко)

| Где | Что |
|---|---|
| Экран входа | номер сборки внизу |
| Мастер → карточка задачи | кнопка «Я на объекте» (GPS + время прибытия) |
| Мастер → выполнение | крупные чек-листы, кнопки-комментарии вместо текста, «Сделать фото» и «Из галереи», сжатие фото |
| Мастер → чат | «Общий чат» / «Лично с диспетчером» |
| Руководитель → Настройки | смена кодов доступа (1111/9999 — только по умолчанию) |
| Руководитель → Бригады | добавление сотрудников + личные коды, аватары-инициалы |
| Руководитель → Проверка | возврат отчёта кнопками-причинами |
| Возврат на доработку | красный баннер у мастера с причиной, снимается при повторной отправке |
