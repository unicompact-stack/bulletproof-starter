# Reference Style

Эта папка — обязательный стиль-ориентир для всех новых начинаний в FSM PRO.

## Что сюда складывать
- скриншоты референсов
- краткие описания того, что именно взять из референса
- заметки по цветам, сетке, карточкам, типографике и поведению интерфейса
- ссылки на локальные превью и макеты

## Правило работы
Перед созданием нового экрана или дашборда сначала смотри эту папку и сверяйся со стилем.

## Текущий ориентир
- светлая рабочая панель исполнителя
- белые карточки на фоне #F4F7FA
- тёмный текст #263238
- синий акцент #168BEA
- зелёный успех #2CCB70
- интерфейс должен открываться локально без сервера, когда это возможно

## Структура продукта
- руководитель: 4 раздела
- бригада: 2 раздела
- без карты, GPS, финансов, чатов и сложных таблиц в базовой версии
- крупные кнопки и минимум текста на экране
