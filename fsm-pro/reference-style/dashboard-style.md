# Dashboard Style Reference

## Основной визуальный язык
- фон #F4F7FA
- белые карточки
- тонкие серые границы #E2E8F0
- тёмный текст #263238
- акцентный синий #168BEA
- зелёные статусы #2CCB70

## Что важно в дашборде
- быстрый обзор задач
- карточки с адресом, статусом и бригадой
- последние задачи, которые требуют внимания
- крупная кнопка основного действия
- короткие и читаемые метрики

## Продуктовые правила
- 1 задача = 1 работа на 1 адресе
- зелёный = выполнено
- оранжевый = ждёт проверки
- красный = нужно исправить
- важные действия держать внизу экрана

## Как делать новые экраны
- не перегружать текстом
- показывать главное первым экраном
- использовать карточную сетку
- оставлять достаточно воздуха между блоками
- держаться того же визуального языка, что и `fsm_mobile_demo.html`
