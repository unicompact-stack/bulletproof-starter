# Голос для проектов — первая локальная версия

Локальный синтез речи на русском на основе Silero v5. Это **не** распознавание речи и не голосовой помощник: программа получает текст и отдаёт звук. В интерфейсе звук сразу воспроизводится. Файлы с результатом она не сохраняет. Клонирование голоса пока не реализовано; встроенные голоса можно менять в любой момент.

## Запуск на Windows

1. Распакуйте архив в обычную папку (например, на рабочий стол). Не запускайте файл внутри окна ZIP.
2. Дважды нажмите `start.bat`. Должен быть установлен Python с командой `py` и модулем `venv`. На первой установке нужен интернет и место на диске: скрипт создаст `.venv` и скачает PyTorch CPU.
3. Держите появившееся окно открытым. Когда откроется браузер, введите текст, выберите голос и нажмите «Озвучить». Если браузер не открылся, перейдите на http://127.0.0.1:8765/ вручную.
4. При первом нажатии «Озвучить» модель Silero скачивается из `models.silero.ai` и сохраняется в папке `models/`. Это может занять несколько минут. Потом озвучка работает локально и может работать без интернета. В дальнейшем для запуска снова откройте `start.bat`.
5. Для остановки закройте окно программы или нажмите Ctrl+C в нём.

Если установка не прошла, пришлите скриншот окна. Некоторые версии Python могут быть несовместимы с текущей сборкой PyTorch; тогда установим поддерживаемую версию Python. Если порт 8765 занят, закройте предыдущую копию сервера.

Текст и звук не отправляются внешнему сервису: синтез выполняется локально, модель и зависимости скачиваются при первой установке. Файл модели — исполняемый пакет PyTorch: используйте только официальный источник, установленный в `server.py`, не подменяйте его сторонним файлом.

## Подключение будущих проектов

Пока программа открыта, локальное приложение или серверный код на этом же компьютере может обратиться к `http://127.0.0.1:8765/api/speak` POST-запросом JSON:

```json
{"text": "Привет! Чем я могу помочь?", "voice": "xenia"}
```

В ответ возвращается `audio/wav` (24 кГц, моно, 16 бит). Проект может сразу воспроизвести полученные байты, не сохраняя их. Поле `voice`: `xenia`, `kseniya`, `baya`, `aidar`, `eugene`; лимит 450 символов на запрос. Ошибки возвращаются JSON-объектом `{"error": "..."}`. Запросы ставятся в очередь, поэтому нельзя рассчитывать на мгновенный ответ.

Пример на Python (только получение байтов; воспроизведение зависит от вашего приложения):

```python
import json
from urllib.request import Request, urlopen
payload = json.dumps({'text': 'Привет!', 'voice': 'xenia'}).encode('utf-8')
request = Request('http://127.0.0.1:8765/api/speak', data=payload, headers={'Content-Type': 'application/json'})
with urlopen(request) as response:
    wav_bytes = response.read()  # передать в проигрыватель вашего приложения
```

Сервис слушает только `127.0.0.1` и не предназначен для публикации в интернет. Запросы из браузера со стороннего сайта / другого порта специально блокируются (нет CORS): для браузерных проектов потребуется безопасный локальный прокси или размещение под одним источником. Не открывайте сервис в сеть без отдельной защиты. Удалённый сайт не может просто так обратиться к нему, если движок запущен на другом компьютере.
