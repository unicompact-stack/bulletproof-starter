Стартовый шаблон для любого проекта с Claude Code + встроенная методология разработки Bulletproof.

Клонируй → открой в VS Code → напиши одну фразу → через ~2 часа у тебя настроенная среда: заполненный бизнес-контекст, правила работы с агентом, 12-этапный workflow разработки, библиотека из 17 готовых промптов, первый план и ретроспектива.

> 👀 **Хочешь увидеть что получится?** Открой пример заполненного проекта — [examples/coffeeshop/](./examples/coffeeshop/). Это вымышленная сеть кофеен с полностью заполненной `.business/`, реальным планом (подписка на напитки) и одной ретроспективой. По нему видно что у тебя окажется через ~2 часа после клонирования.

## TL;DR

1. Клонируй → открой в VS Code → открой Claude Code → напиши «привет»
2. Клод сам проведёт тебя через 11 шагов онбординга (~2 часа)
3. Получишь настроенную среду под твой проект + встроенный Bulletproof + 17 готовых промптов

## Что ты получаешь после онбординга

- 📁 **Папка `.business/`** - второй мозг проекта, заполненный по твоим ответам на интервью (7 блоков: company, products, audience, goals, economics, marketing, assets)
- 📋 **`CLAUDE.md`** - правила работы с агентом под твой стек и тип проекта
- 🛡️ **Bulletproof** (встроен) - 12-этапный workflow разработки: исследование → спека → план с обоснованием → реализация по фазам → проверки → анализ влияния → ревью → деплой. Адаптивный: для мелкой правки 6 этапов, для смены архитектуры все 12
- 🗂 **`specs/`, `research/`, `plans/`, `progress/`, `retrospectives/`** с готовыми шаблонами
- 🔒 **Безопасность:** звуковые хуки, 4 запрета опасных команд, защита от push в main, хук против самообмана, правильный `.gitignore`
- 📚 **Библиотека промптов** - 17 готовых промптов под любые задачи (прогон через Bulletproof, критика плана, Playwright, деплой, «10 причин обосраться»)

## Прежде чем начать

Убедись, что у тебя есть:

- [ ] **VS Code** установлен ([скачать](https://code.visualstudio.com))
- [ ] **Claude Code** (расширение в VS Code) установлен ([инструкция](https://docs.anthropic.com/claude/docs/claude-code))
- [ ] **Подписка Claude** оплачена (Pro $20 или Max $100+)
- [ ] **Авторизация в Claude Code** пройдена
- [ ] (Если ты из РФ) **VPN** одной страны включён - не переключай между странами

Если какой-то пункт не получается - открой [TROUBLESHOOTING.md](TROUBLESHOOTING.md), там решения на все типовые проблемы.

## Как запустить

**Вариант A - через кнопку GitHub:**

1. Нажми **«Use this template»** вверху этой страницы
2. Дай имя своему проекту (например, `moy-magazin-obuvi`)
3. Склонируй к себе: `git clone https://github.com/твой-логин/moy-magazin-obuvi`

**Вариант B - через терминал:**

```bash
git clone https://github.com/artemiimillier/claude-code-starter moy-proekt
cd moy-proekt
rm -rf .git && git init
```

## Что делать дальше

1. Открой папку в **VS Code**
2. Открой **Claude Code** (иконка в левой панели)
3. Напиши любую фразу - `привет`, `начинаем`, `проведи меня`
4. Клод сам начнёт онбординг и проведёт тебя через 11 шагов

**Длительность:** ~2 часа. Можно разбить на 2 сессии (технические настройки + интервью про бизнес) - Клод сам предложит паузу.

## Зачем здесь Bulletproof

Bulletproof ([отдельный репозиторий](https://github.com/artemiimillier/bulletproof), MIT) —
это методология разработки для ИИ-агентов: 12 этапов от исследования до деплоя.
Здесь он **встроен в шаблон** как `.claude/skills/bulletproof/` — ставить ничего не нужно.

**Проблема, которую он решает.** Агент без системы: услышал задачу → написал код → сказал «готово».
На деле: схватил первое решение, поломал соседний модуль, половину критериев не выполнил,
а незавершённость прикрыл фразой «это не входит в задачу».
По данным SWE-CI (Alibaba, 2025), **75% ИИ-агентов вносят регрессии в работающий код**.

**Что меняет Bulletproof:**

| Механизм | Что ловит |
|---|---|
| Исследование с WebSearch | «Изобрёл велосипед, хотя есть проверенное решение» |
| Спека-контракт (`specs/`) | «Готово» по ощущениям вместо «готово» по критериям |
| Challenge Loop | Первое попавшееся решение вместо лучшего |
| Анализ влияния | Сломанный соседний модуль, который найдут через неделю |
| Хук против самообмана | «Не входит в задачу», «сделаю в следующем PR» |

**Адаптивный размер** — не каждой задаче нужны 12 этапов:
**S** (1-2 файла) → 6 этапов, **M** (3-10 файлов) → 10, **L** (10+ файлов) → все 12.
Размер определяет Клод и называет его вслух.

Подробнее — `.claude/skills/bulletproof/SKILL.md` и промпт
[`prompts/methodology/bulletproof-run.md`](./prompts/methodology/bulletproof-run.md).
Как именно сшиты два проекта — в [INTEGRATION.md](./INTEGRATION.md).

## Что этот шаблон НЕ делает

- Не устанавливает VS Code, Claude Code, Node.js (это до клонирования)
- Не оплачивает подписку Claude
- Не настраивает VPN / Google country (решай сам)
- Не отвечает за тебя в интервью про бизнес - **вся ценность в твоих ответах**

## Безопасность

- `.env` в `.gitignore` из коробки - секреты не попадут в публичный репозиторий
- `.business/` в исходном шаблоне содержит плейсхолдеры и tracked в git намеренно. Клод добавит `.business/` в `.gitignore` и снимет с tracking автоматически на последнем шаге онбординга (10a). До этого шага не делай `git commit` вручную, иначе промежуточные данные окажутся в истории
- Клод настраивает 4 запрета опасных команд (`rm -rf`, `curl+export`, `.env`, `wget`) в `settings.json`
- Хук `PreToolUse` блокирует `git push` в main/master, `rm -rf /` и `DROP TABLE`
- Хук `Stop` проверяет: не сдаёт ли Клод незавершённую работу под видом готовой
- Bypass Permissions не включается автоматически - включаешь сам, когда почувствуешь уверенность

**Рекомендуем** включить pre-commit hook для защиты от случайной утечки секретов:

```bash
cp .github/hooks/pre-commit.sample .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

После этого каждая попытка `git commit` будет проверять staged файлы на API-ключи, `.env`, приватные ключи. Если найдёт - заблокирует коммит.

## Обновления шаблона

Когда выйдет новая версия - загляни в [CHANGELOG.md](CHANGELOG.md) исходного репо и скопируй к себе то, что полезно.

**Что можно безопасно обновлять:**
- `prompts/` - новые готовые промпты под задачи
- `TROUBLESHOOTING.md` - новые решения типовых проблем
- `scripts/security-audit.sh` - обновлённые проверки
- `.github/hooks/pre-commit.sample` - улучшения защиты

**Что НЕ трогать при обновлении:**
- `.claude/skills/bulletproof/` — обновляется из своего апстрима по правилам из `.claude/skills/bulletproof/README.md`
- `.business/` - там твои данные, не перезаписывай
- `CLAUDE.md` - он уже под твой проект, не откатывай
- `plans/`, `retrospectives/` - твоя история работы
- `AUTOPILOT.md` - с флагом `completed: true` не нужен больше

Способ обновления - просто скачай нужные файлы вручную. Автоматический `npx`-апдейтер появится в v1.1.0+.

## FAQ

### Bulletproof обязателен? Можно работать без него?

Можно — но хуже. Скил встроен и подхватывается сам: для задач размера S (1-2 файла)
он разворачивает лёгкий цикл, для M и L — полный конвейер.
Если хочешь отключить — удали папку `.claude/skills/bulletproof/`. Но тогда исчезнут
анализ влияния и защита от самообмана, а это два самых полезных механизма методологии.

### Это тот же Bulletproof, что лежит отдельным репозиторием?

Да, методология та же (v5.0, MIT, автор — Артемий Миллер). Отличия этой копии: русский язык,
встроена файлами (не submodule), папки `research/` и `progress/`, завязка на `.business/`.
Полный список — в [INTEGRATION.md](./INTEGRATION.md).

### Почему этот шаблон, а не пустой CLAUDE.md?

Пустой `CLAUDE.md` — это «напиши туда правила сам». Ты не знаешь что туда писать, пока не набил шишки. Этот шаблон — **выжимка методологии после 3 потоков практикума**: `.business/` как второй мозг, `plans/` с критикой через субагентов, `retrospectives/` для памяти между сессиями, встроенный 12-этапный workflow и 17 готовых промптов под типовые задачи. Ты получаешь результат которого иначе достигнешь через 3-4 месяца работы.

### Это бесплатно?

Шаблон — **полностью бесплатно** (MIT). Подписка Claude ($20-200/мес) — отдельно, это продукт Anthropic. Платный практикум Школы Смысло-кодинга — опционально, для тех кому нужна методология на 2-3 уровне и обратная связь.

### У меня уже есть проект — как его интегрировать?

Используй промпт [`prompts/methodology/import-existing-project.md`](./prompts/methodology/import-existing-project.md) — Клод прочитает твой код, структуру папок, README и сам заполнит `.business/` на основе того что найдёт. Вопросов зададёт 5-7 чтобы закрыть пробелы.

### Я не из России. Часть документации русская. Это проблема?

Сейчас шаблон только на русском. Английская версия — в [roadmap](./CHANGELOG.md) v2.0.0. Пока что — всё работает, просто тебе нужно знать русский или готов использовать Google Translate на файлы-подсказки. Промпты внутри ты пишешь на том языке который выберешь на шаге 8 онбординга.

### Сколько токенов Claude сожрёт в месяц?

Сама работа по методологии (план → реализация → ретро) — среднее потребление у предпринимателя с активным проектом: ~15-30 млн токенов/мес. Это укладывается в Claude Max $100. Если работаешь меньше 2 часов/день — хватит Pro $20. Главный расход — интенсивная разработка, а не сам шаблон.

### Сколько времени займёт онбординг?

~2 часа: 11 шагов. Техническая часть (hooks, безопасность, git, Bulletproof) — ~25 минут,
интервью про бизнес — 50-60 минут, остальное — генерация файлов и первый коммит.
Можно разбить на две сессии, Клод сам предложит паузу.

### Что если я закрою ноут посреди онбординга?

Без паники. AUTOPILOT ведёт файл прогресса. Откроешь проект через день → напишешь любую фразу → Клод скажет «вижу мы остановились на шаге N, продолжаем?». Сценарий протестирован.

### Что если AUTOPILOT ошибётся или задаст странный вопрос?

Напиши Issue через [кнопку выше](../../issues) — шаблон «bug-report» попросит нужные детали. Или запусти более узкий промпт вручную: вместо AUTOPILOT целиком — промпты из [`prompts/setup/`](./prompts/setup/) по отдельности.

### Это работает только с Claude Code? А Cursor / Cody / Windsurf?

Рассчитан на **VS Code + Claude Code**. Частично работает в Cursor (структура `.business/`, `plans/`, `retrospectives/` универсальна, промпты тоже). AUTOPILOT заточен под Claude Code и в других IDE может сбиться. Для Codex — читай блок в [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).

### Могу ли я использовать шаблон для коммерческого проекта?

Да. Лицензия MIT. Используй как хочешь, включая закрытый коммерческий софт. Атрибуция в footer README желательна, но не требуется юридически.

### Куда писать если не работает что-то не из этого списка?
