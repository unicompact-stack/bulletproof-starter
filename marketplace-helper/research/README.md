# research/ — артефакты исследования

Сюда Клод складывает результаты этапа 1 (Bulletproof): как всё работает сейчас,
что затронем, что уже придумали до нас.

## Правила

1. **Имя файла:** `YYYY-MM-DD-название-задачи.md`
2. **Исследование — это режим «только чтение».** Никакого кода и правок на этом этапе.
3. **Артефакт обязан заканчиваться рекомендацией.** Список вариантов без вывода — провал этапа.
4. **Обязателен WebSearch:** кто уже решил эту задачу, какой подход считается лучшим.

## Зачем это нужно

Типичная ошибка агента — схватить первое решение, которое пришло в голову.
Исследование заставляет сначала посмотреть, что уже придумали другие, и только потом выбирать.
