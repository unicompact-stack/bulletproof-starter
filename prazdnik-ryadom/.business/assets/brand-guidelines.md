# Бренд и название

## Название

**«Праздник Рядом»** — выбрано владельцем 2026-10-30.

Почему подходит:
- **«рядом»** — правда: один город, выезд на дом, конкретный человек, а не федеральное агентство
- **«праздник»** — сразу понятно, что продаётся, без расшифровки
- работает для детей 8–15 и для взрослых, не запирает в «аниматорах»
- легко запоминается на слух — важно, потому что рекомендация идёт из уст в уста

Как писать: «Праздник Рядом» — ведущий в Йошкар-Оле. В объявлении: «Праздник Рядом — ведущий
для школьников 8–15: квиз, квест, живая гитара».

### Как называется то, что вы делаете

| Контекст | Формулировка |
|---|---|
| Объявление, визитка | Праздник Рядом — ведущий праздников в Йошкар-Оле |
| Для родителей 8–15 | Ведущий для школьников: квиз, квест, гитара |
| Для взрослых по знакомству | Ведущий на юбилей и день рождения |
| Телефонная рекомендация | «Это Праздник Рядом, тот самый ведущий с гитарой» |

### Что отклонили

| Вариант | Почему нет |
|---|---|
| «Заводила» | владельцу не подходит по характеру: «из меня такой себе заводила» |
| «Сам веду» | звучало как слоган, а не имя |
| «Ведущий 12» | цифра региона ничего не говорит родителю |

## Тон

- **Ведущий, а не клоун.** Энергия и юмор без паясничества. Не «заводила» — спокойный,
  уверенный человек, который знает, что будет дальше.
- На «вы» с родителями, на «ты» с детьми.
- Без слащавости: не «праздник мечты», а «два часа, где дети заняты делом».

## Позиционирование одной фразой

> «Ведущий для школьников 8–15 лет: квиз, квест, живая гитара. Без костюмов и хороводов.»

Почему так: аниматоры — для малышей, тамады — для взрослых, между ними пусто.
Живая гитара — то, чего нет ни у аниматора за 1000 ₽, ни у агентства с колонкой.

## Визуал (минимум)

- Цвета: тёмный фон + один яркий акцент. Без радуги и «детских» шрифтов.
- Фото: живые кадры с праздника, не стоковые дети с шариками.
- Логотип: на старте — название текстом. Логотип позже, когда есть заказы.

## Чего избегать

- Персонажей из мультиков, слова «аниматор», «массовик-затейник»
- Клоунских шрифтов и воздушных шаров на афише
- Обещаний «шоу», «спецэффектов», «диджея»
