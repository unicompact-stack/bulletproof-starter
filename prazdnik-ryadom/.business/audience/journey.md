# Путь клиента

```
1. Повод         ДР ребёнка / выпускной / юбилей
2. Поиск         ВК-группы мам, Авито, чат класса, совет подруги
3. Сравнение     5–10 предложений: аниматоры, агентства, тамады
4. Контакт       сообщение или звонок: «сколько стоит и что в программе»
5. Решение       важно: программа под возраст, цена, «не подведёт ли»
6. Праздник      приехал вовремя, отработал, уехал
7. Отзыв         фото/видео, рекомендация в чате — это и есть реклама
8. Повтор        следующий ДР, выпускной, «а посоветуйте ещё»
```

## Где теряются клиенты

| Точка | Что происходит | Что делать |
|---|---|---|
| 2. Поиск | нас там просто нет | быть в 3–4 местах, где реально ищут: ВК-группы мам, Авито, чаты классов |
| 3. Сравнение | мы дороже аниматора, дешевле тамады — непонятно, к кому относиться | называть себя «ведущий для школьников», а не «аниматор» |
| 4. Контакт | отвечаем через сутки | отвечать в течение часа, это половина сделки |
| 5. Решение | «нет отзывов» | видео с пробного выезда + гарантия: не понравилось — не платите за программу |

## Ключевая метрика пути

Не «сколько просмотров», а **сколько обращений превратилось в дату в календаре.**
