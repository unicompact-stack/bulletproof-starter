# Приложение-суфлёр «Праздник Рядом»

Помощник ведущего на планшете: показывает **что говорить**, **что делать**, **сколько осталось**
и что делать, если что-то пошло не так. Работает офлайн, интернет не нужен.

## Что внутри

| Экран | Что делает |
|---|---|
| **Блок** | текущий шаг: время, «Говорю» (крупным текстом), «Делаю» (список с галочками), музыка, игра, «не делать» |
| **Таймер** | сколько осталось до конца блока, кнопки −1 / +1 минута, полоса заполнения |
| **Торт** | обратный отсчёт до торта в шапке, подсветится за 5 минут |
| **Суфлёр** | полноэкранный режим: одна фраза на весь экран, тап — следующая |
| **Что случилось?** | 16 ситуаций: дети не хотят играть, драка, задержали торт, толпятся — с действиями и готовой фразой |
| **Игры** | 35 игр с фильтром по возрасту и поиском, у каждой «как играть» и «если не пошло» |
| **Меню** | сценарии, фразы, чек-лист выезда, настройки (шрифт, тема, время, имена) |

У каждой аварийной ситуации две части: **что делать по шагам**, **что сказать** и строка
**«Что меняется»** — как меняется план и на какой блок прыгнуть. Прыжок ищет блок по смыслу,
поэтому работает во всех трёх сценариях.

## Как открыть на планшете

1. Откройте адрес приложения в браузере планшета (ссылка — в превью проекта).
2. Дождитесь полной загрузки (файлы кешируются).
3. **Добавить на главный экран**: Safari — «Поделиться» → «На экран „Домой“»;
   Chrome — меню ⋮ → «Установить приложение» / «Добавить на главный экран».
4. Запускайте с иконки — откроется без адресной строки и **без интернета**.

## Как пользоваться на выезде

1. Меню → **Сценарии** → выбрать (Дима 10 лет / младший 8–11 / старший 12–15).
2. Меню → **Настройки** → поставить время начала, время торта, имя именинника.
3. Начать с начала (или дождаться времени — приложение само переключит блоки по часам).
4. Ведите по кнопке **«Дальше»**. Если отстали — приложение уже не совпадает с планом:
   жмите «Дальше» вручную, таймер считает от нажатия.
5. Что-то пошло не так — **«Что случилось?»** → выбрать ситуацию → прочитать фразу → «К блоку».
6. Забыли, что говорить — **«Суфлёр»**: одна фраза на весь экран, тап — следующая.

## Полезные детали

- Экран не гаснет, пока приложение открыто (насколько это позволяет браузер).
- Всё состояние сохраняется само: закрыли планшет — открыли на том же блоке.
- Кнопки **−1 / +1 минута** — когда блок затянулся или прошёл быстрее.
- Работает и на телефоне, и на ноутбуке; на планшете удобнее всего в горизонтали.

## Один файл — `index.html`

`python3 build.py` собирает **весь** `index.html`: стили, данные, логика внутри, внешних ссылок ноль.
Этот же файл отдаёт сервер и его же можно скачать и открыть локально:

1. скачать `index.html`;
2. открыть двойным щелчком (компьютер) или из «Файлов» (планшет);
3. работать — интернет и сервер не нужны.

Локально состояние (последний блок, галочки) сохраняется браузером, но на `file://` некоторые
браузеры это запрещают — тогда приложение работает, просто не запоминает прогресс между запусками.

## Как менять содержимое

Все тексты — в `data.js`:

- `SCENARIOS` — сценарии и блоки (что говорю, что делаю, музыка, игра, «не делать»)
- `SITUATIONS` — аварийные ситуации
- `GAMES` — библиотека игр
- `PHRASES` — фразы на все случаи
- `CHECKLIST` — чек-лист выезда

В текстах работают подстановки: `[имя]` — как зовут ведущего, `[ребёнок]` — имя именинника
(оба задаются в настройках, иначе видно `[ваше имя]`).

Правится в любом текстовом редакторе, ничего собирать не нужно. После правки —
обновить страницу и заново «Добавить на главный экран» (или очистить кеш).
