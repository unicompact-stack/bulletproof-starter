# Sociora — копия проекта (sociora.ru)

Статическая копия сайта [sociora.ru](https://sociora.ru) — лендинга ИИ-агента
для ведения соцсетей (Telegram, ВКонтакте, MAX). Все страницы, тексты, тарифы,
юридические документы и интерактив воспроизведены локально, без внешних
зависимостей и обращений к сторонним сервисам.

## Структура

```
sociora/
├── build.py               # генератор: контент + шаблоны → HTML
├── verify.py              # проверка работоспособности копии
├── content/               # markdown-контент 17 страниц (источник текстов)
│   ├── servis-avtopostinga.md ... analogi-smmplanner.md
│   ├── about.md, contacts.md
│   └── offer.md, privacy.md, terms.md, cookies.md, consent.md
├── assets/
│   ├── css/styles.css     # дизайн-система (тёмная тема, адаптив)
│   └── js/main.js         # интерактив без внешних библиотек
├── index.html             # главная (генерируется)
├── *.html                 # 17 внутренних страниц + 404 (генерируются)
├── robots.txt, sitemap.xml, llms.txt   # SEO-файлы (генерируются)
└── README.md
```

## Как запустить

```bash
cd sociora
python3 build.py                    # собрать HTML из контента (один раз)
python3 -m http.server 8080         # раздать копию локально
# откройте http://localhost:8080
```

## Как проверить, что всё работает

```bash
# в отдельном терминале, при запущенном сервере:
python3 verify.py http://127.0.0.1:8080
```

Скрипт проверяет: доступность всех 19 страниц и ассетов (HTTP 200),
все внутренние ссылки и якоря, наличие title/h1/description/cookie-баннера
на каждой странице, интерактивные элементы главной (демо-генератор,
переключатель тарифов, табы аналитики), целостность SEO-файлов.

## Что внутри копии

**Главная (index.html):** герой со статистикой, блок проблем, 4 шага запуска,
6 возможностей, интерактивная аналитика с табами (Общий/ВКонтакте/Telegram/MAX),
блок самообучения, демо-генератор постов (введите нишу — получите пример поста
с превью как в Telegram), сравнение «до/после», тарифы с переключателем
месяц/год (−17%) и пакеты постов, FAQ-аккордеон, финальный CTA.

**17 внутренних страниц:** 10 SEO/продуктовых (сервис автопостинга, автопостинг
в Telegram и ВКонтакте, кросспостинг в MAX, кросспостинг, нейросеть для постов,
контент-план, оформление постов, замена SMM, аналоги SMMplanner), о компании,
контакты и 5 юридических документов (оферта, политика ПД, соглашение, cookie,
согласие).

**Интерактив (assets/js/main.js):** мобильное меню, переключение тарифов
месяц/год с анимацией чисел, табы аналитики с анимированными графиками,
демо-генератор постов (шаблоны для салона красоты, кофейни, фитнеса иgeneric-ниши),
cookie-баннер с запоминанием в localStorage, появление блоков при скролле.

## Примечания

- Кнопки регистрации ведут на боевой `app.sociora.ru/register` (внешние ссылки),
  всё остальное работает локально.
- Яндекс.Метрика и прочие сторонние скрипты намеренно не подключены — копия
  работает полностью автономно.
- Тексты Legal-страниц воспроизведены из оригинала для демонстрации структуры.
