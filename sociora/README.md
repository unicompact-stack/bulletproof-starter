# Sociora — рабочая копия проекта (sociora.ru)

Полноценная локальная копия сайта [sociora.ru](https://sociora.ru): маркетинговый
лендинг + **рабочий личный кабинет** с генерацией постов, соцсетями,
расписанием, аналитикой и тарифами. **Регистрации и входа нет** — кабинет
открывается сразу. Бэкенд — на стандартной библиотеке Python (http.server +
SQLite), внешних зависимостей нет.

## Быстрый старт

Кабинет — на **отдельном сервере**, и **входа/регистрации нет вообще**:
открываешь адрес и сразу работаешь.

```bash
cd sociora
./start.sh                          # запустит оба сервера сразу
# или по отдельности:
python3 server.py 8080              # сайт    -> http://127.0.0.1:8080
python3 cabinet_only_server.py 8082 # кабинет -> http://127.0.0.1:8082
```

- **Кабинет (8082):** `/` — сразу личный кабинет. Там же `/app/`, `/lk/`
  и весь `/api/*`. Никаких `/login`, `/register`, форм и паролей.
- **Сайт (8080):** лендинг. Кнопки «Попробовать»/«Войти» ведут на `/app/`,
  то есть в кабинет.

При первом запуске сервер создаёт владельца кабинета и наполняет его
демо-данными: 2 проекта с анализом ниши, 12 постов в разных статусах,
соцсети и платёж — всё сразу доступно для просмотра и правок.

Проверка:

```bash
python3 verify.py         # 101 проверка: сайт, кабинет, API-сценарий
node lk/test_views.js     # рендер всех 14 разделов кабинета
```

## Что умеет личный кабинет

Разделы названы и расположены как в оригинале (sociora.ru):

| Раздел | Возможности |
| --- | --- |
| Дашборд | «Здравствуйте!», KPI (всего/на проверке/запланировано/опубликовано), остаток постов с прогресс-баром, последние посты |
| Лента постов | фильтры по статусам, карточки постов с действиями: на проверку, опубликовать, в расписание, перегенерировать, удалить |
| Быстрый пост | выбор проекта и рубрики → готовый текст с промптом для картинки |
| Аналитика | просмотры/подписчики/ER, график по дням, «голос канала», топ постов, AI-инсайт |
| Конкуренты | мониторинг ниши + анализ аудитории и болей по проекту |
| Самообучение | профиль голоса канала, статистика обучения, тон |
| База знаний | инструкции по разделам и частые вопросы |
| Темы | анализ ниши (мок-ИИ), темы с кнопкой «Написать пост», создание проектов |
| Расписание | запланированные посты + автоплан на неделю (7 постов) |
| Соцсети | подключение/отключение Telegram, ВКонтакте, MAX с проверкой лимита тарифа |
| Настройки | имя и тон голоса канала |
| Биллинг | текущий тариф, все тарифы, пакеты постов, история операций (демо-оплата) |
| Профиль | аккаунт и сводка по контенту |
| Поддержка | контакты и документы |

## API (кратко)

```
GET  /api/me
GET/POST/DELETE /api/projects, /api/projects/{id}, /api/projects/{id}/analyze
GET/POST /api/posts, /api/posts/generate, /api/posts/{id}, /api/posts/{id}/regenerate,
     /api/posts/{id}/status (approve/schedule/publish/draft), DELETE /api/posts/{id}
GET/POST/DELETE /api/socials
GET  /api/analytics?network=all|telegram|vk|max
GET/POST /api/tariffs, /api/tariffs/choose, /api/packs/buy, /api/payments
POST /api/settings          {name, tone}
POST /api/plan/week
GET  /api/admin/stats, /api/admin/users, /api/admin/posts, /api/admin/payments
POST /api/admin/users/{id}   {action: block|plan|balance|admin, ...}
```

Аутентификации нет: сервер сам определяет владельца кабинета
(`owner@sociora.local`, создаётся при первом запуске) и работает от его имени.
Никаких cookie, токенов, форм входа и паролей в сценарии использования.

### Админ-панель (на будущее)

Эндпоинты `/api/admin/*` и страница `/admin/` в коде есть, но владельцу
кабинета они закрыты (403) — как договорились, админкой пока не занимаемся.
Чтобы включить: `UPDATE users SET is_admin=1 WHERE email='owner@sociora.local'`.


## Проверка работоспособности

```bash
python3 server.py 8080              # сайт + API (в одном терминале)
python3 cabinet_only_server.py 8082 # отдельный сервер кабинета (в другом)
python3 verify.py http://127.0.0.1:8080   # 101 проверка: сайт, кабинет, API
node lk/test_views.js               # рендер всех 14 разделов кабинета
```

```
Итого: 101 проверок, пройдено 101, провалено 0
Всё работает: кабинет открывается сразу, без регистрации и входа.
```

Проверяется: доступность страниц лендинга и ассетов, внутренние ссылки,
структура (title/h1/description), интерактив лендинга, редиректы
`/app → /app/` и `/admin → /admin/`, что на месте `/login` и `/register`
открывается кабинет (а не формы), кнопка «Новый пост», баланс постов в
шапке, отдельный сервер кабинета на 8082, а также **сквозной API-сценарий
без всякой авторизации**: проект → анализ ниши → генерация поста
(баланс 300→299) → отправка на проверку → публикация → перегенерация →
постановка в расписание → подключение соцсети → аналитика по сетям → тариф
→ пакет постов → контент-план на неделю → удаление поста.

## Как это устроено

- **Мок-ИИ** (`server.py`): анализ ниши по ключевым словам (салон красоты,
  кофейня, фитнес, универсальный шаблон), генерация 10–15 тем и полноценных
  постов с рубриками, «перегенерация по комментарию».
- **Оплата тарифов** — демонстрационная: активирует план и начисляет посты,
  реальных списаний нет.
- **Публикация в соцсети** — демонстрационная: пост получает статус
  «опубликован» и стартовую статистику; реальные токены не используются.
- **База** — `data/app.db` (SQLite), создаётся при первом запуске. Владелец
  кабинета и демо-наполнение засеиваются автоматически
  (`seed_sample_content`).
- **Админ-панель** — отдельное SPA в `admin/`, доступно только пользователям с
  флагом `is_admin`; все `/api/admin/*` возвращают 403 обычным пользователям.

## Примечания

- Тексты юридических страниц воспроизведены из оригинала для демонстрации
  структуры; для боевого использования их нужно заменить своими.
- Яндекс.Метрика и сторонние скрипты не подключены — копия автономна.
- Кнопки поддержки ведут на реальный Telegram @sociora_support.
