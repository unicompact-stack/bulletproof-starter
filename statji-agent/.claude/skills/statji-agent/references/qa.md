# Проверки статьи: коды и что делать

Запуск:

```
python3 engine/qa.py content/articles/<slug>.md      # одна статья
python3 engine/qa.py --corpus                        # все статьи + отчёт по дублям
python3 engine/qa.py content/examples/_bad-example.md --json
```

Выход: `exit 0` — все проверки пройдены; `exit 1` — есть `fail`; `exit 2` — ошибка запуска.

## Коды

| Код | Что проверяет | Почему это важно | Что делать при fail |
|---|---|---|---|
| **S** | Frontmatter: обязательные поля, `objection` ровно один, `slug` совпадает с именем файла, типы | Без объекта возражения статья бесцельна | Заполнить поля по `_template.md` |
| **T** | Title 40–70, description 120–180, H1 присутствует и не длиннее 70 | Обрезка в выдаче = потерянный клик | Переписать заголовок |
| **L** | Объём 550–1100 слов | Короче — не закрывает возражение | Добавить раздел, а не «воду» |
| **K** | Целевой запрос: в H1, в первом абзаце, в ≥2 H2 | Иначе поиск не поймёт, о чём статья | Переписать заголовки под запрос |
| **F** | **Каждое число-цифра есть в `content/facts.md`** или помечено `≈`/«оценка» | Выдуманная цена = потерянный клиент | Добавить факт с источником или убрать цифру |
| **O** | Есть блок оффера и ровно одна ссылка-призыв на `/zamer/` | Статья без действия не приносит заявок | Добавить один блок CTA |
| **R** | Нет формулировок из стоп-листа, нет упоминаний конкурентов по названию | Юридический риск | Переформулировать |
| **C** | Структура: ≥3 H2, есть «Как проверить», абзацы ≤ 90 слов | Читаемость и доказательность | Разбить абзацы, добавить раздел |
| **H** | Человеческий язык: средняя длина предложения ≤ 25 слов, доля коротких слов ≥ 75% | Фильтр «воды нейросети» | Убрать канцелярит и длинные периоды |
| **D** | Пересечение с другими статьями по 5-словным шинглам < 15% | Дубли конкурируют друг с другом в поиске | Развести темы, убрать общие куски |
| **M** | Внутренние ссылки ≥ 2 и все относительные ссылки существуют | Связность кластера | Добавить ссылку на стволовую статью |
| **X** | Нет выдуманных кейсов и отзывов (имена, «клиент сказал», «наши клиенты отмечают») | Репутация | Убрать или заменить на проверяемый факт |

## Как читать отчёт

```
PASS  F  факты                    numbers=14 unknown=0
FAIL  K  ключевой запрос          'как выбрать подрядчика' в H2: 1 (нужно ≥2)
```

Слева — код, справа — фактическое значение. Если значение не сходится,
**правится статья**, а не порог проверки. Понижение порога — это самообман,
ровно тот, от которого метод и защищает.

## Про «зелёный» QA

`exit 0` **не значит «статья хорошая»**. Он значит: нет выдуманных цифр, есть структура,
оффер и нет юридических мин. Смысл и пользу текста проверяет второй агент (шаг 4б в `SKILL.md`)
и человек. Не подменяй одно другим.
