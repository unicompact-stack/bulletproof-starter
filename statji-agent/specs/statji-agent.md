# Спека: агент-статейник для СК «СтройЦех 12»

**Статус:** accepted v1 · **Дата:** 14.10.2026 · **Режим:** normal→deep (деньги, публикации, репутация)

## Зачем (одна фраза)

Получать заявки на бесплатный замер из поиска статьями, которые закрывают возражения
и не содержат выдуманных цифр.

## Контракт: что должно быть правдой

Жирным — то, что можно проверить командой, а не на глаз.

### C1. Статью можно опубликовать только после автопроверки

**`python3 engine/qa.py content/articles/<slug>.md` возвращает exit 0** и JSON с
`"passed": true`. Иначе файл не попадает в сайт (`engine/web.py build` его пропускает).

### C2. В статье нет ни одной цифры, которой нет в реестре фактов

**Каждое число с единицей (₽, %, м², дней) присутствует в `content/facts.md`
или помечено `≈` (оценка) / `оценка`.** Выдуманная цена = красный статус.

### C3. Статья закрывает ровно одно возражение

В frontmatter указан `objection: O1..O7` из `audience/objections.md`;
**ровно одно значение**, без списка.

### C4. Статья приводит к действию

В тексте есть **блок оффера** (замер + смета за 24 часа) и **одна** ссылка-призыв на
страницу замера. QA проверяет наличие обоих.

### C5. Статья решает задачу поиска

**Целевой запрос (`target_query`) есть в H1, в первом абзаце и минимум в двух H2.**
Title 40–70 символов, description 120–180.

### C6. Ничего юридически рискованного

**Ни одной формулировки из стоп-листа** («лучший», «самый дешёвый», «№1», «100% гарантия»,
«гарантируем навсегда») и ни одного упоминания конкурентов по названию.

### C7. Человеческий язык

**Средняя длина предложения ≤ 25 слов, абзац ≤ 90 слов, доля длинных слов (< 12 букв) ≥ 75%.**
Это эвристика против «воды нейросети», а не оценка качества текста.

### C8. Текст не дублирует уже опубликованное

**Пересечение по 5-словным шинглам с любой другой статьёй корпуса < 15%.**

### C9. Приёмку делает не автор

Публикация возможна только с флагом человека (`--approve`), а проверку текста делал
**отдельный проход второго агента**, который видит только: спеку, файл статьи, отчёт `qa.py`.
Автор не может принять свою статью сам.

### C10. Видно, что статья принесла

Заявки пишутся в `data/leads.jsonl` с полем `ref` = slug статьи.
**`python3 engine/report.py` показывает заявки по каждой статье**; если данных нет — «неизвестно».

## Границы (что НЕ делаем)

- Не публикуем автоматически без человека.
- Не пишем отзывы, кейсы и имена клиентов.
- Не обещаем SEO-результат: гарантировать позиции в поиске нельзя.
- Не делаем «контент-план на 50 статей» — очередь растёт по мере проверки гипотез.

## Что считается «готово» для этой итерации

1. Скилл агента (`SKILL.md` + 4 референса) — как выбирает темы, пишет, проверяет, публикует.
2. Движок: `qa.py` (проверки C2–C8), `site.py` (сайт + приём заявок), `report.py` (C10).
3. 3 опубликованные статьи + 1 статья-пример, которая **специально заваливает QA**.
4. Тесты движка: `python3 -m unittest discover -s engine/tests -v` — зелёные.
5. Работающий сайт с формой заявки и дашбордом.
