# Правила работы с этим проектом

Проект делает ИИ-помощник. Ниже — то, что нельзя нарушать даже ради «улучшения».

## Категорически нельзя

1. **Публиковать без подтверждения человека.** По умолчанию — сухой прогон. Флаг `--live`
   ставит человек. Никогда не выставляй его сам и не обходи проверки.
2. **Придумывать цифры.** Любое число в посте приходит из `data/<тематика>/facts/`.
   Если факта нет — пост помечается `needs-data`, и это правильное поведение, а не баг.
3. **Ослаблять проверки в `src/checks.js`.** Если проверка мешает — сначала понять почему,
   потом менять. Удаление или ослабление правила без нового теста = регресс.
4. **Публиковать площадку, чей адаптер не написан.** Заглушка обязана честно падать.
5. **Выдумывать даты проверки.** Дата ставится только из факта. Подставленная сегодняшняя дата
   хуже отсутствующей.
6. **Писать в факт то, чего нет на странице-источнике.** Источник обязан быть в `source`.

## Ограничения по существу

- **Никаких npm-зависимостей.** Только стандартная библиотека Node. Если кажется, что нужна
  библиотека — сначала напиши, почему нельзя тридцать строк на месте.
- **Правило проверки без теста — не готовая работа.** Новое правило, новая тематика,
  новая площадка — всё проверяется тестом в `test/`.
- **Числа в посте — только в блоке фактов и с датой.** Абзацы объясняют смысл, но не содержат
  процентов и рублей. Это требование ст. 28 ФЗ «О рекламе».
- **Не смешивать тематики.** Данные лежат в `data/<тематика>/` и `queue/<тематика>/`.
  Код, который пишет в другую папку, — ошибка.
- **Стиль текста не выдумывать.** Формулировки лежат в `hooks.json` и `bodies.json`.
  Нейросеть для формулировок подключается по `docs/AI-STEP.md` — и только после факт-чекера.

## Проверка перед сдачей

```bash
npm test                                    # все тесты зелёные
npm run generate -- --subject tbank --rubric karta --dry   # пост собирается и проходит проверки
PROFILE=vacancies npm run generate -- --subject bystro --rubric vakansiya
npm run publish -- --id <id>               # сухой прогон, наружу ничего не уходит
```

## Чего в проекте нет (не предлагай это как готовое)

- Живой публикации: в среде сборки нет сети, всё проверено на фикстурах
- Адаптеров Telegram и Дзен
- Нейросети в цикле сборки
- Агента уровнем выше (надзор за деньгами) — он только спроектирован в `docs/AGENT-ABOVE.md`
