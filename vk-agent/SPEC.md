# SPEC — VK Agent, технический каркас

**Дата:** 2026-10-04 · **Статус:** каркас готов, проверен на фикстурах
**Методология:** Bulletproof, размер **L** (новый сервис, больше 10 файлов)

---

## 1. Задача

Владелец ведёт группу ВКонтакте про банковские продукты. Сейчас каждый пост — это ручная работа:
найти актуальные условия, не соврать с цифрой, не забыть оговорку, оформить, выложить.
Нужен агент, который делает это сам, а человек только смотрит результат.

**Для кого:** владелец группы (один человек, не программист, не маркетолог).
**Что болит:** время на рутину и риск ошибиться в цифре или формулировке.

## 2. Что должно получиться (в границах первого шага)

Агент, который по короткой команде («пост про карты Альфы») собирает готовый пост:
сам находит актуальные условия у банка, сам держит структуру и оговорки, сам проверяет
себя по формальным правилам и показывает результат в панели. Публикация — по кнопке.

**В границах:** сбор фактов, сборка текста по шаблонам, механические проверки, панель превью,
публикация в ВК, тесты.
**Вне границ первого шага:** генерация текста нейросетью, картинки, автопостинг по расписанию,
второй (проверяющий) агент, аналитика охватов, вторая площадка. Всё это — в `docs/ROADMAP.md`.

## 3. Критерии готовности

| # | Критерий | Как проверяется | Состояние |
|---|---|---|---|
| 1 | Факты собираются со страниц банка в структуру с датой и источником | `npm run fetch -- --bank tbank --offline`, разбор отчёта | ✅ |
| 2 | Каждая цифра в посте имеет дату проверки рядом | тест «пост про карту Т-Банка» + глазом по тексту | ✅ |
| 3 | Пост не собирается, если обязательных фактов нет | `npm run generate -- --bank vtb --rubric karta` → `needs-data` | ✅ |
| 4 | Запрещённые формулировки блокируют публикацию | `test/checks.test.js`, кейс `stopword-block` | ✅ |
| 5 | Цифра без даты блокирует публикацию | кейс `number-without-date` | ✅ |
| 6 | Реклама без маркировки не публикуется | кейс `ads-marking` | ✅ |
| 7 | Человек видит пост и правки до публикации | `npm run preview` → панель | ✅ (проверено локально) |
| 8 | По умолчанию публикация — сухой прогон | `npm run publish -- --id <id>` → «в ВК ничего не ушло» | ✅ |
| 9 | Реальная публикация работает | `--live` с ключом ВК | ⛔ не проверено: в песочнице нет доступа к api.vk.com |
| 10 | Парсер работает на живых страницах банков | `npm run fetch -- --bank alfa` без `--offline` | ⛔ не проверено: в песочнице нет интернета |
| 11 | Тесты зелёные | `npm test` → 48/48 | ✅ |
| 12 | Работает на чистой машине без зависимостей | `npm test` сразу после клонирования | ✅ (зависимостей нет) |

Критерии 9 и 10 закрываются на компьютере с интернетом и ключом ВК — это первый шаг после
переноса проекта, см. `plans/`.

## 4. Ограничения, принятые осознанно

- **Без внешних библиотек.** Только стандартная библиотека Node — проект должен запускаться
  через год без «обновите 400 пакетов»
- **Факты — в JSON-файлах, а не в базе.** Один банк = один файл: видно глазами, правится руками,
  не требует установки СУБД
- **Текст собирается шаблонами, а не нейросетью.** Сначала контур с проверяемыми цифрами,
  потом живой язык. Наоборот — риск, что модель придумает ставку
- **Публикация только вручную.** Пока проверок мало, автомат без присмотра — лишний риск
- **Один банк = один файл фактов.** Кросс-банковские сравнения («у кого выше ставка») требуют
  отдельного слоя и в первый шаг не входят

## 5. Риски

| Риск | Что делаем |
|---|---|
| Банк поменяет вёрстку — парсер найдёт не ту цифру | Дата и источник у каждого факта, обязательные факты по рубрике, кэш страницы в `data/cache/`, тесты на фикстурах |
| Шаблонный текст надоест читателю | Хуки и абзацы расширяются конфигом; следующий шаг — нейросеть поверх тех же фактов |
| Претензии по рекламе (ст. 28 ФЗ «О рекламе») | Обязательные факты по рубрике, оговорки по типу продукта, стоп-слова, флаг рекламы и маркировка |
| Владелец не сможет поддерживать | Никаких зависимостей, все настройки в читаемых JSON и markdown, ошибки объясняют, что делать |

## 6. Что считается «сделано» для этого шага

Каркас считается готовым, когда человек на своей машине может пройти путь
«собрал факты → собрал пост → посмотрел в панели → опубликовал» и ни на одном шаге
не увидел цифру без источника. Пункты 9 и 10 из таблицы закрываются при первом живом прогоне.
