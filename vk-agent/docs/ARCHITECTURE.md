# Устройство проекта

Коротко: настройки и знания — в читаемых файлах, логика — в маленьких модулях, никаких
зависимостей и никакой скрытой магии. Всё, что попадает в пост, проходит через факты и проверки.

## Поток данных

```
1. config/banks.json     — что парсить (адреса страниц банков)
2. src/fetch.js          — загружает страницы (или фикстуры в офлайне)
3. src/parse.js          — вытаскивает цифры, суммы, сроки, новости
4. knowledge/facts/*.json — база фактов: значение + дата + источник
5. src/generate.js       — собирает текст: хук, лид, факты, абзацы, призыв, оговорка, хештеги
6. src/checks.js         — 14 проверок; ошибки блокируют публикацию
7. queue/*.json          — черновик поста
8. panel/page.html       — человек смотрит, правит, жмёт «Опубликовать»
9. src/publish.js → src/vk.js — запись на стене сообщества (по умолчанию сухой прогон)
```

## Модули

| Файл | Ответственность | Что не делает |
|---|---|---|
| `src/util.js` | Файлы, даты, `.env`, разбор аргументов | Ничего не знает про банки и посты |
| `src/bank.js` | Банки из конфига, чтение и слияние фактов | Не ходит в сеть |
| `src/config.js` | Загрузка рубрик, хуков, абзацев, стоп-слов, оговорок | Без логики |
| `src/history.js` | Журнал сборок и публикаций (`data/history.jsonl`) | Без логики отбора |
| `src/parse.js` | Разбор HTML: проценты, суммы, сроки, таблицы, новости | Ничего не сохраняет |
| `src/fetch.js` | Загрузка страниц, офлайн-фикстуры, запись фактов | Не собирает текст |
| `src/render.js` | Мини-шаблонизатор (`{{var}}`, `{{#block}}`, `{{.}}`) | Без бизнес-логики |
| `src/generate.js` | Выбор рубрики, темы, хука, абзацев; сборка поста | Не публикует |
| `src/checks.js` | Правила проверки поста | Не правит текст |
| `src/vk.js` | Вызовы API ВК | Не решает, что публиковать |
| `src/publish.js` | Публикация: перепроверка, отправка, история | Не обходит ошибки проверок |
| `src/preview.js` | HTTP-сервер панели и JSON-API | Не содержит текстов |
| `src/cli.js` | Команды для терминала | Тонкий слой |

Правило разделения: модуль, который решает (проверки, генерация), не занимается побочными
эффектами (сеть, файлы). Поэтому логику можно проверять тестами без подмены сети.

## Форматы данных

**Факт** (`knowledge/facts/<bank>.json`) — единица знания:

```json
{
  "label": "Кэшбэк",
  "value": "до 15%",
  "date": "2026-09-16",
  "source": "https://www.tbank.ru/cards/",
  "product": "Дебетовая карта Black"
}
```

**Пост** (`queue/<дата>-<банк>-<рубрика>.json`):

```json
{
  "id": "2026-10-04-tbank-karta",
  "status": "ready",
  "text": "...готовый текст...",
  "facts": [{ "key": "cashback_rate", "value": "до 15%", "date": "2026-09-16", "line": "• Кэшбэк — до 15% (проверено 16.09.2026)" }],
  "checks": { "status": "ok", "errors": [], "warnings": [] }
}
```

**История** (`data/history.jsonl`) — по строке на событие: `kind` = `generated` | `published` |
`scheduled`. Нужна для двух вещей: ротация тем журнала и предупреждение «похожий пост недавно».

## Решения и почему так

| Решение | Почему |
|---|---|
| Никаких npm-зависимостей | Проект должен открываться и работать через год; зависимостей нечего обновлять |
| `fetch` + `AbortSignal.timeout` из Node 20 | Хватает для загрузки страниц, не тащит axios и cheerio |
| Свой разбор HTML на регулярках, а не cheerio | Страницы банков — простой HTML; регулярки прозрачны и не ломаются на обновлении библиотеки. Цена — хрупкость к вёрстке, компенсируется тестами и кэшем страниц |
| Факты отдельно от текста | Текст можно переписать (шаблоном или нейросетью), цифры остаются проверенными |
| Проверки в коде, а не в голове модели | Одна и та же цифра без даты всегда даёт одну и ту же ошибку |
| Офлайн-режим на фикстурах | Позволяет проверять парсер там, где нет интернета, и в тестах |
| Панель на одном HTML-файле | Нет сборки, нет сборщика, открывается сразу |

## Тесты

`npm test` — 48 тестов, каждый файл тестов работает в своей временной копии проекта
(`test/helpers.js`), поэтому настоящие факты и очередь не портятся.

| Файл | Что проверяет |
|---|---|
| `test/parse.test.js` | Разбор фикстур: проценты, таблицы ставок, суммы, даты, новости |
| `test/collect.test.js` | Офлайн-сбор: попадание фактов в базу, отсутствие дублей, отчёты |
| `test/generate.test.js` | Сборка поста: структура, дата у цифры, детерминизм, `needs-data` |
| `test/checks.test.js` | По одному случаю на каждое правило проверок |
| `test/publish.test.js` | Блокировка плохих постов, сухой прогон, остановка батча |

Правило: новое правило в `checks.js` без теста — не готовая работа.
