# Заметки о банках

По одному файлу на банк: `<bank_id>.md`, где `bank_id` совпадает с id в `config/banks.json`.
`alfa.md` — заполненный пример.

Зачем это нужно: факты приходят из парсера и меняются каждый месяц, а заметки о банке — это то,
что не меняется. Агент читает их, когда собирает пост.

Что писать:

- **как обращаться** — полное и короткое название, чего не делать (не писать слитно, не склонять)
- **сильные стороны** — о чём писать чаще
- **о чём не писать** — запреты конкретно по этому банку
- **особенности** — подписки, отдельные условия, частые изменения
- **куда отправить читателя** — сайт, раздел помощи

Чего не писать: цифры и ставки. Для цифр есть `knowledge/facts/` — там у каждой цифры есть дата
и источник. Цифра из заметки в пост не попадёт и проверку не пройдёт.
