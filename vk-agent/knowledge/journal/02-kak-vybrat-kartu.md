# Тема: как выбрать карту

Читатель выбирает дебетовую карту и сравнивает только по кэшбэку, забывая про обслуживание и лимиты.

## Ключевая мысль
Карта выбирается по трём цифрам: обслуживание, кэшбэк, лимит кэшбэка. Кэшбэк без лимита ничего не значит.

## Что можно писать
- Три цифры, на которые смотреть: стоимость обслуживания и условие бесплатности, ставка кэшбэка, месячный лимит
- Что «до 10%» часто означает «в двух выбранных категориях и не больше N ₽ в месяц»
- Сравнение карт по цифрам из `knowledge/facts/`, если у обеих стоят даты проверки

## Что нельзя
- Писать «лучшая карта» без оговорок
- Ставить кэшбэк без лимита рядом
- Обещать одобрение

## Структура поста
1. Хук про разницу между рекламной и реальной цифрой
2. Чек-лист из трёх пунктов
3. Пример на 2-3 картах с датами проверки
4. CTA: «проверь условия на сайте банка»

## Пример хука
«"Кэшбэк до 10%" звучит красиво, пока не дочитаешь до лимита: 3 000 ₽ в месяц.»

## Пример CTA
«Перед оформлением сверь три цифры: обслуживание, кэшбэк, лимит. Ссылки — в описании сообщества.»
