# План: технический каркас агента ВК

**Дата:** 2026-10-04 · **Размер задачи:** L · **Статус:** выполнен (кроме живого прогона)

## Зачем

Нужен агент, который сам собирает посты про банковские продукты для группы ВКонтакте, а человек
только смотрит результат. Этот план — про техническую часть: движение цифр и текста, проверки,
панель, публикация. Нейросеть для формулировок — следующий этап.

## Ограничения среды (важно для честного статуса)

В песочнице, где собирался проект, **нет доступа в интернет**: ни к сайтам банков, ни к `api.vk.com`.
Поэтому:

- парсер проверен на фикстурах (`test/fixtures/banks/`), а не на живых страницах
- публикация проверена сухим прогоном и тестами, а не реальной записью в сообществе
- ключ ВК не проверялся через `npm run status` (ждёт заполненного `.env`)

Первый живой прогон — на машине владельца. Порядок и ожидаемые проблемы — в README,
раздел «Если парсер ничего не нашёл».

## Что сделано сверх плана

- Офлайн-режим разбора (`--offline`) — без него проект нельзя было бы проверить в песочнице,
  а теперь он ещё и ускоряет отладку парсера
- Механизм вариантов: «Переделать» в панели даёт тот же пост с другим хуком и абзацами
- Проверка «задвоенное слово» — появилась после реального бага «до до 15%» при склейке шаблона и факта
