# База фактов: описание формата

Факты — единственный источник цифр для постов. Агент не придумывает числа: если факта нет,
пост помечается `needs-data` и не публикуется.

Сами файлы фактов сюда **не кладутся** — это локальные данные конкретной машины. Они лежат в
`data/banks/facts/<банк>.json` и в git не попадают. Здесь только описание формата, чтобы при
создании тематики понимать, чего ждёт код.

## Откуда берутся

- `npm run fetch -- --subject alfa` — загружает страницы банка из `profiles/banks/subjects.json`
  и раскладывает найденное по файлам `data/banks/facts/<банк>.json`
- `npm run fetch -- --subject alfa --offline` — то же, но на тестовых фикстурах из
  `test/fixtures/banks/`, без интернета

## Формат

```json
{
  "subject_id": "alfa",
  "updated": "2026-10-04",
  "facts": {
    "cashback_rate": {
      "label": "Кэшбэк",
      "value": "до 10% в выбранных категориях",
      "date": "2026-09-15",
      "source": "https://alfabank.ru/everyday/debit-cards/",
      "product": "Дебетовая карта «Альфа»"
    }
  }
}
```

- `value` — значение так, как оно показано читателю
- `date` — когда это значение проверено; именно она печатается рядом с цифрой в посте
- `source` — страница, откуда взято. Проверяющий агент и человек смотрят сюда
- `product` — необязательно: к какому продукту относится факт, если на странице их несколько

## Правила

- Дата без `source` — это не факт, а мнение агента
- Пустое значение не перетирает старое: слияние оставляет предыдущее, если новое пустое
- При конфликте двух источников побеждает факт с более свежей датой
- Факт старше `FACT_TTL_DAYS` (по умолчанию 30 дней) вызывает предупреждение, но не блок:
  решение принимает человек
