# Альфа-Банк — что нужно знать агенту

## Как обращаться в постах
- Название: `Альфа-Банк` (полное), в заголовке допустимо `Альфа`
- Не склонять аббревиатуру, не писать «АльфаБанк» слитно
- Дружелюбный тон, без канцелярита

## Сильные стороны (о чём писать чаще)
- Наименование продукта и категории кэшбэка часто меняются — их надо брать из свежих фактов, не из этой заметки
- Ведёт много «лимитированных» акций с партнёрами — подходит для рубрики «акция» с жёстким дедлайном

## О чём НЕ писать
- Не сравнивать напрямую с конкурентами по названию («лучше, чем X») — в проверке это даёт предупреждение
- Не публиковать ставки без даты получения: банк меняет их часто

## Особенности
- Есть отдельные условия для держателей подписок — уточнять в фактах, а не додумывать
- Если в факте нет точного числа, лучше пост не публиковать (проверка поставит `needs-data`)
