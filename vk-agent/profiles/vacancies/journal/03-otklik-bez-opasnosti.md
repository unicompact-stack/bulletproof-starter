# Отклик без потери денег

Обычный отклик на вакансию ничего не стоит. Стоит другое: покупка курсов, «собеседования»,
которые просят перевести деньги, и ссылки на сторонние приложения.

Работодатель с вакансией на сайте — норма. Вакансия в чате без контактов и с требованием
оплатить что-либо — не норма.
