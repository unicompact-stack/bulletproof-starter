# Заметки по работодателям

По одному файлу на работодателя: `<subject_id>.md`. Файл читает человек, когда правит текст
поста вручную или настраивает тон. Формат — front-matter и свободный текст:

```md
---
subject_id: bystro
tone: просто и по делу
---

# БыстроДоставка

Курьер на автомобиле. Вилка зарплаты широкая — всегда показывать «от X до Y».
Не писать «зарабатывай от 100 тысяч»: это обещание, а не условие.
```

Что туда класть: особенности оформления, типичные жалобы, что писать нельзя, чем компания
отличается. Файл на эти данные не влияет — только подсказка для человека.
