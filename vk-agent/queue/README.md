# Очередь постов

Здесь лежат черновики: `<дата>-<банк>-<рубрика>.json` — результат `npm run generate`.

В git очередь не хранится: это рабочий стол, а не архив. История публикаций — в ВК, и дублировать
её в репозитории незачем.

## Что внутри файла

- `text` — готовый текст поста (его видно в панели, его же отправляет публикация)
- `facts` — список фактов с датами и источниками; у каждого знания есть `line` в том виде,
  в каком он попал в текст
- `checks` — результат проверок: `errors` (блокируют публикацию) и `warnings` (не блокируют)
- `status`:
  - `ready` — готов к публикации
  - `needs-data` — не хватает обязательных фактов, надо запустить `npm run fetch`
  - `blocked` — проверки нашли ошибку (запрещённая формулировка, цифра без даты и т. п.)
  - `published` — уже в ВК, повторно не отправится

## Как посмотреть, что в очереди

```bash
npm run checks              # сводка по всей очереди
npm run checks -- --id 2026-10-04-tbank-karta   # разбор одного поста
```

Удалять черновики можно свободно: они собираются заново одной командой.
