# Скилл «Голос для проектов»

Это инструкция для ИИ-помощника, который поможет вам позже сделать озвучку для проектов. **Это не сама программа и не голосовая модель.** Сейчас ничего дополнительно устанавливать не нужно.

## Как пользоваться позже

1. Скачайте архив и распакуйте его.
2. Откройте в вашем ИИ-помощнике папку проекта, над которым хотите работать. Подойдёт помощник, который умеет читать файлы, изменять их и запускать команды — не обязательно Claude Code.
3. Передайте ему файл `SKILL.md` или попросите прочитать его и напишите:

> Прочитай приложенный SKILL.md. Помоги мне сделать локальную озвучку для проектов. Сначала объясни, что будешь делать и что потребуется скачать. Без моего согласия ничего не устанавливай.

Если помощник умеет подключать скиллы, можно добавить в него папку с `SKILL.md` по инструкции именно вашего помощника. У разных помощников путь и способ подключения отличаются. Если помощник умеет только общаться в чате, можно вставить текст файла в чат, но выполнять установку и команды придётся вручную.

## Что учтено

- Русская озвучка приятными готовыми голосами или своим голосом по записи.
- Возможность сменить голос; чужой голос — только с разрешения его владельца.
- Предпочтение локальной работе без интернета после установки; онлайн-вариант только по согласованию.
- Озвучивание ответа без сохранения каждого аудиофайла; подключение к будущим проектам.
- Windows 11, 32 ГБ ОЗУ, NVIDIA RTX 3050 с 6 ГБ видеопамяти — эти сведения стоит перепроверить перед установкой.
- Прошлая ошибка с моделью: сначала разобраться в причине, а не повторять установку вслепую.

Модель, программы и компоненты для озвучки позже будут скачиваться отдельно, если вы одобрите установку. Размер, качество голоса и скорость работы нужно проверять для конкретной модели и компьютера.
