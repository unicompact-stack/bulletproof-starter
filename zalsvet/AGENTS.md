# Правила работы над демо пульта

Файл для агента. Человеку можно не читать. Суть: простой русский, своё демо, не копия чужого сайта.

## Кто заказчик

Новичок. Пишет по-русски. Отвечать просто, без жаргона.

Если вещь сложная — сначала одно предложение «что это», потом «зачем». Не начинать с терминов.

## Что это за проект

Учебное демо для ведущего: личный кабинет, экран для зала, телефон гостя и окно музыки.

На экране имя **ЗалСвет**. Папка кода — `zalsvet/`. Слово чужого бренда не писать ни в интерфейсе, ни в именах файлов и папок.

Стек простой: Node и Express. Данные — один JSON-файл `data/db.json`, отдельной базы нет. Если файла нет, демо создаётся заново, и коды праздников могут стать другими.

Два запуска, это не одно и то же:

- `npm run start:cabinet` — открыл адрес и уже в кабинете, пароль не нужен. Для проверки это основной режим.
- `npm start` — сайт с входом. Это другой режим, не подменять им кабинет.

После правок сервер нужно запустить заново, иначе в браузере старая версия.

## Чужой сайт

Чужой сервис не копируем.

Нельзя переносить дословно чужие тексты, логотип, имя автора, цены, точные куски оформления и скриптов. Нельзя оставлять это имя в коде, письмах демо и названиях файлов.

Можно смотреть только принципы: тёмный спокойный вид, понятная иерархия, лёгкое движение.

Цель — своё демо, которое ощущается собранным.

## Как должно выглядеть

1. Тёмный зал: фон `#07060c`, золото `#e8c27a`, один акцент `#8b5cf6`. Бурый и оранжевый как основа не возвращать.
2. Картинки только свои. Чужие скриншоты не вставлять.
3. Лёгкое появление и реакция на наведение. Без мигающей «ёлки».
4. Два шрифта: Unbounded на экране зала, Manrope в пульте.
5. Кнопки и отступы по одной сетке, не «на глаз».

## Что уже можно запускать

В кабинете по-настоящему работают только: заставка, колесо, таймер, квиз, табло, тайминг.

Остальные пункты каталога можно показывать, но с замком и короткой причиной. Они не должны запускаться.

Музыкальный пульт — отдельное окно `/dj`, не картинка на экране зала. Из него можно вернуться в кабинет. Браузер не умеет отдать зал и наушники в два разных выхода сразу: это ограничение, его не обещать.

Фото и видео заставки — файлы в `public/uploads/`, не огромный JSON.

Демо-почта: `demo@zalsvet.local`.

## Чего не делать

- Не деплоить и не пушить без прямой команды.
- Не коммитить, если не просили сохранить в git.
- Не хранить пароли, токены и ключи в коде.
- Не добавлять функции «на всякий случай».
- Не смешивать сюда другие проекты, в том числе аватар-хост.
- Не выдавать выключенный раздел за рабочий.

## Как делать задачу

1. Сначала сказать, что делаем и как поймём, что готово.
2. Менять только нужные файлы.
3. Если коммит просили — маленький, с понятным текстом, в индекс только нужные файлы.
4. В конце короткий список: что изменилось. По-русски.
5. Надписи в интерфейсе тоже по-русски.

Проверка без лишнего: главная открывается, кабинет пускает без пароля, экран зала и `/dj` отвечают. Полный `npm run check` не гонять без просьбы.
