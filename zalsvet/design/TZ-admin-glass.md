# ТЗ: перенести стиль «Dark Neumorphic Glass» в пульт Аватара

**Источник стиля:** макет `Аватар/avatar_host/111/neumorphic-host-control-panel/`  
**Токены и CSS:** `Аватар/avatar_host/design/pulte-glass-tokens.md`  
**Цель:** `/admin` выглядит как современный пульт (стекло, 3D-кнопки, неон), логика Flask не ломается.  
**Статус:** ТЗ до явной команды «Реализуй фазу N» — **код не меняем**.

---

## 1. Что делаем

Оформление панели ведущего (`templates/admin.html` + подключаемый CSS) в стиле референса:

1. Тёмный фон + фиолетовый неон + Manrope  
2. Панели-«стекло» с blur  
3. Кнопки с 3D-объёмом (primary violet, dark secondary, coral play)  
4. Sidebar с цветными плитками-иконками  
5. Mode-bar с chip-ами  
6. Превью экрана/сцены в «живом» стекле  
7. Единые радиусы и состояния hover/active/focus  

## 2. Что НЕ делаем

1. Не переписываем API/SSE/TTS  
2. Не тащим React/Vite  
3. Не подключаем макет как есть  
4. Не красим `/host` так же плотно (зрителям — чище; можно только фон/кнопку оверлея)  
5. Не удаляем функции (фразы, сценарий, звук, медиа)  
6. Не меняем PIN/авторизацию  

## 3. Файлы

| Файл | Роль |
|------|------|
| `templates/admin.html` | разметка + точки классов |
| `static/css/admin-glass.css` *(новый)* или вставка в head | вся дизайн-система |
| `design/pulte-glass-tokens.md` | источник токенов |
| `111/neumorphic-host-control-panel/` | временный макет (можно удалить после переноса) |

Предпочтительно: **отдельный CSS-файл**, не размазывать 1000 строк inline в HTML.

## 4. Экраны / блоки admin

Забираем **визуальный язык**, структуру разделов оставляем текущую:

- Верх: заголовок + время + статус эфира (live-dot)  
- Слева или сверху: навигация карточек → **nav-item + цветной tile**  
- Карточки: фон `.panel` glass  
- Кнопки: «Озвучить» / «Сохранить» → **btn-primary**  
- Вторичные: сброс, пропуск → **btn-dark**  
- Play фраз/эфира → **btn-play** coral (если есть)  
- Фразы / сценарий / звук: chips для наборов и target (локально/экран)  
- Inputs: тёмные inset-поля, focus = neon-soft outline  

## 5. Чек-лист качества

- [ ] Одинаковая высота контролов в группах  
- [ ] `:focus-visible` у всех кнопок  
- [ ] Active state виден (translateY + тень)  
- [ ] Текст читаем (muted не ниже contrast ~4.5 на important)  
- [ ] На 1280px нет обрезки mode-bar (wrap)  
- [ ] PIN-форма тоже в стиле (тёмное стекло, primary кнопка)  
- [ ] SSE/кнопки API работают как раньше (ручной прогон)  

## 6. Приёмка

1. Открыть `/admin` → PIN → пульт  
2. Сравнить с макетом: панели, primary, chips, sidebar  
3. Прогнать: озвучить текст, фраза в наборе, «на экран», смена карточки  
4. `/host` — экран зала без «пультового» шума
