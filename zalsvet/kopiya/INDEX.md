# Задание: собрать с нуля копию пульта «ЗалСвет»

Это один файл. Его целиком отдают другой нейронке. Не надо открывать старые ТЗ, чужой React-макет и не надо «улучшать» вид. Нужна рабочая копия того, что уже получилось.

Коротко вставить в другую нейронку:

> Собери с нуля учебное демо пульта ведущего «ЗалСвет» по файлу INDEX.md. Стек: Node + Express + один JSON-файл, без базы и без React. Кабинет открывается без входа. Вид бери только из этого файла: тёмная сетка, фиолетовые объёмные кнопки, коралловая кнопка «Второй экран», шрифты Exo 2 и Unbounded. Раскладка — верхняя полоса на всю ширину, слева список разделов, справа экран зала. Экран зала оставь концертным: золото, лучи, плавная смена. Не называй продукт Pulte. Не включай закрытые разделы. Не рисуй пустые вкладки и фальшивые проценты.

---

## 1. Что это

Учебный пульт ведущего для праздника. Ведущий на ноутбуке выбирает, что видит зал на проекторе. Гости при необходимости заходят с телефона по коду.

Имя продукта: **ЗалСвет**.  
Подпись у знака: **СЦЕНА**.  
Заголовок вкладки: **Пульт ведущего — ЗалСвет**.

Запрещённые имена в интерфейсе, файлах и папках: Pulte, PULTEVENT, PultDemo, EventPult. Чужой сайт и чужой React-макет — только память о стиле кнопок, не образец раскладки и не источник кода.

Язык интерфейса: русский.

---

## 2. Стек

- Node.js и Express.
- Один JSON-файл с данными. Базы нет.
- Обычные HTML, CSS и JS. Без React, Vite, сборщика и второго админа.
- Две команды запуска, их нельзя подменять:
  - `npm start` — сайт с входом.
  - `npm run start:cabinet` — кабинет без входа. Для проверки нужен он.
- Сервер слушает `0.0.0.0` и порт из `PORT`. Если порта нет, кабинет берёт `8080`.
- Кабинет включается переменной `OPEN_CABINET=1`. Тогда адрес `/` сразу открывает пульт, без логина.

Зависимости демо: `express`, `qrcode`.

## 4. Раскладка пульта. Это факт, не макет

Пульт занимает всю высоту окна. Это сетка, не две плавающие карточки.

```
колонки: 248px | остальное
ряды:    56px на всю ширину
         остальное: слева список, справа сцена
```

Схема:

```
┌──────────────────────────────────────────────┐
│ ☰  ЗалСвет СЦЕНА   [Кабинет Музыка Свадьба] │
│                         Второй экран  Телефон │
│                         На весь экран  🔔 🔊 А│
├──────────────┬───────────────────────────────┤
│ Праздники    │                               │
│ 21:04        │      экран зала 16:9          │
│ дата         │      справа зум − 100% +      │
│ название     │                               │
│ поиск   ⚙    ├───────────────────────────────┤
│ ВЕЧЕР +набор │  чипы текущего раздела        │
│ разделы      ├───────────────────────────────┤
│              │  Сохранить   На экране   Демо │
```

На ширине до 980px левая колонка прячется и выезжает кнопкой ☰. Экран зала остаётся 16:9.

Знак слева: квадрат 32×32, фон `#12101a`, обводка `#d8b4fe`, шеврон `#a855f7`. Это свой знак, не чужой логотип.

## 6. Кнопки, вкладки, наведение

Стиль кнопок взят из идеи «тёмное стекло + толщина снизу». Из-за низкой полосы 56px толщина маленькая: нижняя грань **3px**, не 6px. Кнопки около 32–36px высотой, сильно скруглены.

Общее для всех кнопок:

- при наведении текст белеет, кнопка светлеет (`brightness` около 1.16) и получает фиолетовое свечение `drop-shadow(0 0 8px rgba(168, 85, 247, 0.85))`, обводка `#d8b4fe`;
- коралловая кнопка при наведении светится кораллом, не фиолетовым;
- при нажатии кнопка опускается на 2px;
- фокус с клавиатуры: обводка 2px цвета `#d8b4fe`, отступ 2px;
- если у человека отключено движение, убрать плавные переходы.

Виды:

| Что | Как выглядит |
|---|---|
| Верхние вкладки «Кабинет», «Музыка», тип праздника | Лежат в утопленном тёмном лотке. Сами прозрачные, текст приглушённый. Наведение — фиолетовая заливка. |
| Обычные действия «Телефон», «На весь экран» | Тёмный градиент `#2a3140 → #151a23`, светлая верхняя кромка, тёмная нижняя грань. |
| «Второй экран» | Коралловый градиент `#ffb59e → #f97362 → #e8442a`, белый текст, тёплое свечение. Это не круглая кнопка play: текст должен быть виден. |
| «Сохранить» | Фиолетовый градиент `#c48afd → #a855f7 → #8c2fe6`, белый текст, фиолетовое свечение. |
| Круглые 🔔 и 🔊 | 36×36, тёмный градиент, круглая форма. |
| Буква пользователя | Круг с фиолетовым градиентом `#c084fc → #7c3aed`. |
| Чипы под экраном | Тёмные капсулы. Выбранный чип фиолетовый и светится. Редкие действия — пунктирная обводка. |
| Пункт слева | Строка со цветной плиткой 32×32. Выбранный пункт — фиолетовая «подушка» и светлая верхняя кромка. |

| Окна и подсказки | Тёмное стекло, фиолетовая рамка, лёгкое свечение. |

Полоска под экраном — вдавленная тёмная панель, радиус около 20px. Рамка самого экрана тонкая светлая, без золотого ободка. Картинку внутри рамки не перекрашивать.

## 7. Что делает каждая кнопка

Идентификаторы не выкидывать: по ним скрипт находит кнопки.

| Кнопка | id или признак | Действие |
|---|---|---|
| ☰ | `#sideToggle` | На узком экране открывает левый список. |
| Кабинет | `data-open="cabinet"` | Короткое меню: праздники, КП, партнёрка. Это учебные заглушки-окна, не новый сайт. |
| Музыка | `data-open="dj"` | Открывает `/dj` в отдельном окне. Из DJ можно вернуться в кабинет. |
| Тип праздника | `#typeBtn` | Меняет тип текущего праздника. |
| Второй экран | `#secondScreen` | Открывает `/s/КОД` в окне `zalsvet-screen`. |
| Телефон | `#phoneBtn` | Показывает код гостя и ссылку `/j/КОД`. |
| На весь экран | `#fullBtn` и `#dockFull` | Разворачивает экран. |
| 🔔 | `#bell` | Короткие уведомления. |
| 🔊 | `#soundBtn` | Включает и выключает звук. Память: `localStorage` ключ `pe-sound`. |
| Буква | `#avatar` | Имя ведущего. В кабинете без входа это демо-пользователь. |
| Праздники | `#openHolidays` | Список карточек праздников. |
| ⚙ | `#openSets` | Наборы разделов: Свадьба, Детский, Корпоратив, Базовый. |
| + набор | `#addSet` | То же, что наборы. |
| Поиск | `#search` | Фильтрует разделы по названию. |
| Раздел слева | `data-tool` | Включает инструмент, если он разрешён. Иначе замок и объяснение. |
| Звезда | `data-pin` | Закрепляет раздел. Это местная пометка, не сервер. |
| Сохранить | `#saveScene` | Сохраняет текущую сцену. |
| Зум − / + | `#zoomOut` `#zoomIn` | Масштаб картинки внутри рамки. Подпись `#zoomLabel`. |
| Часы | `#clock` `#dateLine` | Местное время и дата. |
| Название вечера | `#showLine` | Название выбранного праздника. |
| Строка состояния | `#liveLine` | Что сейчас на экране. |
| Демо | `#demoPill` | Пометка, что это учебная сборка. Не кнопка. |

Чипы зависят от раздела. Общие поверх экрана: **Салют**, **Конфетти**, **Фанфары**. Они не сменяют раздел, а вспыхивают поверх. Конфетти остаётся внутри экрана зала, не на пульте.

Заставка: поле заголовка, режимы «Обычная / Фото / Слайдшоу / Видео», кнопки настройки надписи, фото, слайдшоу, видео, праздника и файлов.  
Колесо: «Крутить» и «Имена». Минимум два имени.  
Таймер: 1, 3 и 5 минут, пауза.  
Квиз: «На экран», «Ответ», «Дальше».  
Табло: плюс к команде и «Объявить».  
Тайминг: кнопки пунктов плана, текущий подсвечен.

Закрытый раздел не прятать. На нём замок. Нажатие объясняет, что в проверочной сборке он выключен. Сервер на такую попытку отвечает отказом.

## 8. Что реально включено

Работают только шесть сценических инструментов:

- `splash` — заставка;
- `wheel` — колесо гостей;
- `timer` — таймер;
- `quiz` — квиз на экране;
- `board` — табло команд;
- `timing` — тайминг вечера.

DJ не является инструментом сцены. Он открывается отдельным окном. На сцене DJ-пресет не включать.

Остальной каталог можно показать в списке, но `enabled: false`. Группы для ощущения полного пульта: про гостей, викторины, слова, музыка, телефоны гостей, живые, служебное. Не надо делать все эти игры. Достаточно названия, короткой фразы и замка.

Связь инструмента и света зала:

| Инструмент | Свет |
|---|---|
| заставка, тайминг | обычный зал |
| колесо | чуть теплее, лучи уже |
| квиз | холоднее, зал тише |
| табло | свой пресет табло |
| таймер | свой пресет таймера |

Пока инструмент тот же, обновление мгновенное. Когда инструмент сменился, свет и картинка переходят плавно, около 350 мс, без чёрной паузы.

## 9. Экран зала. Его в последнем проходе не переделывали

Это отдельная страница внутри рамки пульта и в окне проектора. Она не должна выглядеть как пульт: без левого меню и без стеклянных панелей управления.

Фон почти чёрный `#05040a`. Поверх — мягкий фиолетовый и золотой свет, фото тёмного зала с прозрачностью около 0.32, четыре луча сверху, пыль, виньетка. Заголовок крупный, шрифт Unbounded, цвет тёплый `#f5f1ea`, не неоновая капсула пульта. Золото зала: `#e8c27a`. Фиолетовый зала: `#8b5cf6`.

Смена раздела меняет силу фото, оттенок и угол лучей. Переход около 350 мс. Не выключать лучи и не заменять зал плоской фиолетовой плашкой.

Кнопка «Включить звук» на зале есть, потому что браузер сам звук не пускает. Она стеклянная и тихая, без двойного неона.

Готовые виды надписи заставки: золото, белая, неон, детская. Фото и видео не стираются при смене цвета надписи.

## 12. Адреса данных

Не менять пути и вид JSON, если копируешь этот пульт рядом с уже готовым сервером. Если собираешь с нуля, сделай те же пути.

- `GET /api/health` — имя, признак кабинета, список включённых инструментов.
- `GET /api/catalog` — группы и разделы.
- `GET /api/auth/me` — текущий пользователь. В кабинете без входа не отвечать «войдите».
- `GET /api/events` и `POST /api/events` — список и новый праздник.
- `GET /api/events/:id` и `PATCH /api/events/:id` — карточка.
- `POST /api/events/:id/action` — действие сцены. Тело `{ "action": "..." }`.
- `POST /api/events/:id/media` — фото или видео как data URL.
- `GET /api/crm` — карточки праздников.
- `GET /api/public/:code` — то, что видит экран зала.
- `POST /api/join/:code` и `POST /api/join/:code/answer` — гость.
- `GET /api/qr` — картинка кода.

Действия `action`, которые должны работать:

- `setTool` — только для шести включённых. Иначе ошибка «Этот раздел в проверочной сборке выключен».
- `splashUpdate` — заголовок, подзаголовок, режим, шаблон, фото, видео.
- `overlay` — `confetti`, `salute`, `fanfare`.
- `wheelNames`, `wheelSpin`.
- `timerStart`, `timerPause`.
- `quizOpen`, `quizReveal`, `quizGoto`.
- `boardScore`, `boardAnnounce`.
- `timingSet`.

Ответ действия: `{ ok: true, live, event }`. Экран зала читает публичную версию без личных полей гостей.

Секреты, ключи оплаты и настоящие пароли в код не писать. Пароль демо — только учебный.

## 13. Чего не делать

- Не переписывать пульт на React и не подключать чужой макет как страницу.
- Не менять работающие `id`, `data-*` и адреса API ради красоты.
- Не прятать рабочие кнопки.
- Не включать закрытые игры «чтобы было полнее».
- Не красить рекламный сайт как пульт.
